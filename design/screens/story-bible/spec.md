# story-bible · 설정 항목 · 이름 넣기 · 요약 카드 (계획 — Mac 0.6.0)

설정 폴더의 인물 · 장소 · 세력 · 용어를 **형식 있는 시트**로 두고, 에디터가 그 이름을 안다(ADR-0010, 기획 docs/research/2026-10-27-story-bible-v2.md).
따로 떨어진 화면이 아니라 app-shell 의 에디터 · 시트 목록 · 인스펙터 · 메뉴에 얹힌다. 프로토타입이 없어 planned.

원칙: **쓰는 흐름에 끼어들지 않는다**(부를 때만 뜸, 조합 중 아무것도 안 함, 시스템 단축키와 안 겹침) · **칸을 채워야 동작하는 기능은 없다** · **텍스트가 정본**.

## 1. 설정 항목
- 만들기
  - 시트 메뉴 · 폴더 컨텍스트 메뉴 · 시트 목록 ＋ 버튼의 메뉴 · 팔레트: **새 인물 · 새 장소 · 새 세력 · 새 용어**. 지금 폴더에 `entry_template` 텍스트로 만들고 이름 줄에 커서.
  - 에디터에서 글을 고르고 컨텍스트 메뉴 · 팔레트 **"설정 항목으로 만들기 ▸ 인물 / 장소 / 세력 / 용어"**: 고른 글이 이름. 설정 폴더(이름이 "설정" / "Lore" 인 폴더, 없으면 둘째 폴더, 하나뿐이면 지금 폴더)에 만들고 **에디터는 그대로**(토스트 "서윤을 설정에 만들었어요 · [열기]").
- 에디터에서 보기 — 텍스트는 그대로, 모양만:
  - front matter 블록: `---` 줄은 흐리게(`ink.markup`), `키:` 는 `ink.tertiary` caption 굵기로 라벨처럼, 값은 본문색. 블록 아래 여백.
  - `## 칸 제목` 은 칸 이름처럼: `#` 기호 흐리게, 제목은 `type.label` · `ink.secondary`. 위 여백을 조금 더.
  - 빈 칸(제목 아래 글 없음)은 제목 한 줄만 — 따로 접지 않는다.
- **칸 더하기**: 항목 시트의 컨텍스트 메뉴 · 팔레트 "칸 더하기 ▸ (그 종류의 추천 칸 중 아직 없는 것) · 직접 이름 짓기…". 시트 끝에 `\n\n## 이름\n` 을 넣고 커서. 추천 칸 — 인물: 원하는 것 · 두려운 것 · 관계 · 비밀/복선 · 변화 / 장소: 있었던 일 · 자주 오는 인물 / 세력: 근거지 · 비밀 / 용어: 예문.
- 시트 목록 행: 항목이면 제목 앞에 종류 아이콘(인물 `user` · 장소 `map-pin` · 세력 `flag` · 용어 `book-a`), 둘째 줄 = 한 줄 소개(없으면 발췌).

## 2. 이름 넣기 (부를 때만)
### `@`
- 줄 머리 · 공백 뒤 · 여는 따옴표/괄호 뒤에서 `@` 를 치면 후보 창이 커서 아래에 뜬다. 그 밖(이메일 등)에서는 아무것도 안 뜸.
- `@` 뒤 글자로 좁힘: 이름 · 별칭의 앞부분 · 포함 · **초성**(`ㅅㅇ` → 서윤). 조합 중인 글자도 포함해 거른다.
- 후보 행: 종류 아이콘 · 이름(별칭으로 맞았으면 "윤이 · 서윤") · 한 줄 소개(흐리게, 말줄임) · 마지막 등장 "238화". 최대 8행. 순서: 정확히 맞음 → 최근 등장 순 → 이름순.
- 키(조합을 거친 뒤 `doCommandBy` 에서 받음): ↑↓ 고르기 · Return / Tab 넣기(`@…` 를 지우고 이름 또는 고른 별칭) · ⇧Return `@` 와 친 글자 그대로 두고 닫기 · Esc 닫기(친 글자 둠). 맞는 후보가 없거나 공백 · 줄바꿈을 치면 닫힘. `@@` → `@` 한 글자, 창 안 뜸.
- 후보 창은 키보드 포커스를 가져가지 않는다(에디터가 계속 입력을 받음). VoiceOver: 고를 때마다 후보를 읽어줌.
### ⌥Esc (단어 마무리)
- NSTextView 표준 `complete:`. 커서 앞 낱말(조사 뺀 앞부분)로 시작하는 이름 · 별칭이 있으면 그것을 맨 위에, 시스템 낱말 후보는 그 아래.
- 편집 메뉴 "이름 넣기 ⌥Esc"(AppCommand) — 팔레트 · 단축키 표에도.
### 공통
- 후보는 지금 작품의 설정 항목(본문에서 찾지 않음 항목도 후보에는 나옴).
- Esc 우선순위: 한글 조합 → 후보 창 → 집중 모드 · 에디터만 → 시스템 단어 완성.
### 구현 (Mac) · 결정
- 코드: `Editor/NameCompletion.swift`(창 · 키 · 밑줄) · `Model/Bible.swift`(후보 거르기 · 초성) · `App/AppModel+Bible.swift`(캐시). 원고 텍스트 뷰에는 갈고리만.
- 캐시 `AppModel.bible`: 작품을 열 때 바로, 개요가 다시 읽히거나 항목 시트가 저장되면 0.3초 뒤, 다른 시트가 저장되면 5초 뒤(마지막 등장 순서). 타자마다 부르지 않는다.
- 후보 창: 키를 받지 않는 자식 패널(`NSPanel` nonactivating, `canBecomeKey = false`), `firstRect(forCharacterRange:)` 로 `@` 아래(화면 끝이면 위). 스크롤하면 따라가고, 창이 키를 잃으면 닫힌다. 행을 눌러도 넣는다.
- 여는 자리: 줄 머리 · 공백 · `" ' “ ‘ 「 『 ( [ { 《 〈 【 < （ ［` 뒤. 작품에 항목이 하나도 없으면 `@` 는 그냥 글자(창도 `@@` 처리도 없음).
- 거르기: 대소문자 무시, 앞부분 · 중간 어디든, 초성은 글자마다(`ㅅㅇ`, `서ㅇ` 도). **마지막 글자는 조합 중일 수 있어** 덜 된 음절도 맞춘다 — `유` → 윤, `오` → 와(겹모음), `성` → 서+윤(받침이 다음 음절 첫소리로 넘어감), `닭` → 달+고(겹받침). 한 항목은 한 행: 정확히 맞은 이름/별칭 → 이름 → 처음 맞은 별칭.
- 순서: 정확히 맞음 → `bible` 순서(core: 마지막 등장 최근 순, 안 나온 것은 이름순). 앞부분 맞음을 중간 맞음보다 올리지 않는다(명세대로).
- 행의 "238화"는 회차 번호가 있을 때만 보인다(번호 없는 시트 제목은 소개를 가려서 뺌. 카드에는 제목도 나온다).
- Return 이 왔을 때 아직 조합 중인 글자가 있으면 먼저 확정(`unmarkText`)하고 **텍스트에서 다시 거른 뒤** 넣는다. 실제 한글 IME 는 확정(insertText) → `insertNewline:` 순서로 보내는데, 어느 쪽이든 넣는 이름은 최신 글자 기준.
- ⇧Return: `NSApp.currentEvent` 의 ⇧ 로 가린다(`insertNewline:` · `insertNewlineIgnoringFieldEditor:` 둘 다). 줄바꿈도 넣지 않는다.
- 넣기: `Coordinator.replace`(서식 명령과 같은 길) — 되돌리기 한 번에 `@…` 가 돌아온다. 맞는 것이 없어 닫힌 뒤의 Return/Tab 은 원래대로 줄바꿈/탭.
- VoiceOver: 열 때 "이름 후보 n개" + 첫 행, ↑↓ 마다 "이름(별칭 · 이름), 한 줄 소개, 238화", 넣으면 "서윤 넣음", `@@` 는 "닫았어요" — `announcementRequested`.
- ⌥Esc: `completions(forPartialWordRange:)` 가 이름 · 별칭(앞부분 · 초성, 낱말보다 긴 것)을 앞에, 시스템 후보를 뒤에. `rangeForUserCompletion` 은 낱말 그대로 맞는 이름이 없고 조사를 뗀 앞부분은 맞으면 그 앞부분만(`벼리에` → `벼리`, 넣으면 `벼리섬에`). 메뉴 항목은 `complete:` 를 부른다(표시는 ⌥⎋, 단축키 표 "서식" 묶음).

## 3. 요약 카드
- 여는 법: 커서가 이름 위(또는 바로 뒤)에 있을 때 **⌥⌘R**(보기 › 설정 카드) · 이름을 포스 클릭. 마우스를 올려 여는 것은 환경설정(기본 꺼짐, 켜면 1초 뒤 · 타자 뒤 3초 동안 안 뜸).
- NSPopover, 이름 아래. 내용 순서: 종류 아이콘 · 이름 · 상태(있으면) / 한 줄 소개 / **마지막 등장 N화** · 그 회차 대사 2–3줄(`Appearance.lines`) / 말투 / 호칭 / 최신 변화("20화부터: …", `## 변화` 의 마지막 항목) / [항목 열기] (Return). 없는 칸은 줄째 생략. Esc · 아무 키 입력으로 닫힘(입력은 에디터로).
### 구현 (Mac) · 결정
- 코드: `Editor/EntryCardPresenter.swift`(팝오버 · 포스 클릭 · 마우스 올림) · `Views/EntryCard.swift`(내용, 인스펙터와 같은 뷰).
- 이름 찾기는 캐시로 앱에서(`NameMatcher.name(at:)`): 커서가 있는 줄에서 이름 · 별칭이 커서를 덮거나 커서 바로 앞에서 끝나면, 가장 긴 것. **본문에서 찾지 않음 항목도 카드는 연다**(core `mentions_in` 은 그런 항목을 빼서 쓰지 않음). 이름이 아니면 경고음.
- **마지막 등장은 지금 연 시트를 뺀 가장 최근 회차**(`appearances` 의 끝에서). 쓰는 회차는 이미 보고 있으니, "지난번에 어디서 나왔지"가 더 쓸모 있다고 판단. 다른 회차가 없으면 지금 시트.
- 칸은 제목 글자로 알아본다(ko · en, 대소문자 무시): 한 줄 소개 · 소개 · 뜻 / Summary · Meaning, 말투 / Voice · Speech, 호칭 / Forms of address · Address, 변화 / Changes. 상태는 front matter `상태` / `status`.
- 팝오버는 `.transient`, 에디터가 키를 계속 받는다. Return 으로 항목 열기는 **부른 카드(⌥⌘R · 포스 클릭)만** — 마우스를 올려 뜬 카드에서는 Return 이 그냥 줄바꿈.
- 포스 클릭: `quickLook(with:)` 에서 포인터 아래 글자(`characterIndex(for:)`)가 이름이면 카드, 아니면 시스템 찾아보기.
- 마우스 올림(환경설정, 기본 꺼짐): 켜면 그때만 `mouseMoved` 추적 영역을 단다. 1초 머물면 열고, 마지막 입력(타자 · 조합) 3초 안엔 안 연다. 포인터가 이름을 벗어나면 닫는다.

## 4. 인스펙터 · 참조
- 참조 탭 맨 위 "이 시트에 나온 항목": `mentions_in` 결과(나온 차례, 같은 항목 한 번), 행 = 아이콘 · 이름 · 한 줄 소개. 누르면 카드 내용을 참조 탭에 펼침. 입력이 멈추고 1초 뒤 갱신(조합 중엔 안 함).
- 손으로 고른 참조 시트는 그 아래 그대로.
- 항목 시트를 열면 정보 탭에 **나온 회차**(`appearances`): "238화 · 3번" 행, 누르면 그 시트 그 자리로.
### 구현 (Mac) · 결정
- `AppModel.sheetMentions`: 시트를 열 때 바로, 그 뒤 입력이 1초 멈추면 `mentions_in`(저장 전 글 그대로). 조합 중이면 1초씩 미룬다. 항목이 없는 작품에서는 부르지 않는다.
- 펼친 카드의 마지막 등장은 펼칠 때 한 번만 찾는다(다시 그릴 때마다 core 를 부르지 않게).
- 나온 회차는 **최근 회차부터**(긴 연재에서 아래로 내려가지 않게). 번호가 없는 시트는 제목. 행을 누르면 그 시트를 열고 첫 언급을 고른다. "본문에서 찾지 않음" 항목은 그렇다고 적는다.

## 5. 이름 표시 (선택)
- 환경설정 › 에디터 "본문의 설정 이름에 밑줄"(기본 꺼짐). 켜면 점선 밑줄 `ink.tertiary`, TextKit 2 렌더링 속성으로만(저장 텍스트 · 조합 중 안 건드림).
### 구현 (Mac) · 결정
- **렌더링 속성 대신 텍스트 뷰가 직접 그린다.** `NSTextLayoutManager` 의 렌더링 속성은 색(`foregroundColor` · `backgroundColor`)만 그리고 `underlineStyle` 은 그리지 않았다(macOS 26 에서 확인: 같은 범위에 배경색은 보이고 밑줄은 안 보임). 그래서 `ManuscriptTextView.draw` 가 이름의 글자 조각(`enumerateTextSegments`) 아래에 1pt 점선을 긋는다. 저장 텍스트 · 속성은 그대로라 원칙은 같다.
- 범위는 `sheetMentions`(1초 뒤 갱신)에서, 지금 글자가 여전히 그 이름 · 별칭인 것만. 고친 문단의 밑줄은 다음 갱신까지 빼고, 그 뒤 범위는 글자 수 변화만큼 옮긴다. 조합 중에는 바꾸지 않는다.
- 같은 환경설정 묶음 "설정 항목"에 §3 의 "마우스를 올리면 설정 카드"(기본 꺼짐)도 있다.

## 6. 설정 가져오기
- 파일 메뉴 "설정 가져오기…" → 노션 내보내기 .md 파일이나 폴더 고르기 → 종류 고르기(인물 · 장소 · 세력 · 용어) → 미리 보기 표(원본 · 이름 · 짝지은 키 n · 칸 n) → [가져오기] 로 지금 작품 설정 폴더에. 전부 되거나 전부 안 됨. 끝나면 토스트.
