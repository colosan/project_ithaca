# export · 내보내기

## 들어오는 길
- 시트 / 폴더 / 작품의 컨텍스트 메뉴 → 내보내기

## 내용 (초안)
- 범위: 시트 하나 · 폴더 전체(순서대로 이어 붙임) · 작품 전체
- 대상:
  - **연재 플랫폼에 붙여넣기** — 클립보드로. 문단 사이 빈 줄, 들여쓰기, Markdown 기호 제거 규칙을 고른다
  - 파일 — 형식 [미정]
- 미리보기: 내보낼 결과를 오른쪽(또는 아래)에 그대로

## 열린 질문 (PRODUCT.md)
