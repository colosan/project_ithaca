# export · 내보내기

## 들어오는 길
- 시트 / 폴더 / 작품의 컨텍스트 메뉴 → 내보내기

## 내용
- 범위: 시트 하나 · 폴더 전체(순서대로 이어 붙임) · 작품 전체
- 대상:
  - **연재 플랫폼에 붙여넣기** — 클립보드로. 문단 사이 빈 줄, 들여쓰기, Markdown 기호 제거 규칙을 고른다
  - 파일 — txt · md · docx. epub 은 목록에 "준비 중"으로만 (PRODUCT.md 검토 필요)
- 미리보기: 내보낼 결과를 오른쪽(또는 아래)에 그대로

## 상태
| state | 무엇 |
|---|---|
| `paste` | 붙여넣기용. 규칙 4개(빈 줄 · 첫 줄 들여쓰기(전각 공백) · Markdown 기호 지우기 · 제목 넣기) |
| `file` | 파일. 형식 하나 고르기. 파일은 제목을 넣고 빈 줄로 나눈다. md 만 Markdown 기호를 남기고, docx 미리보기는 제목을 제목 모양으로 |

- 기본값: 빈 줄 ○ · 들여쓰기 ✕ · 기호 지우기 ○ · 제목 ✕ — 연재 플랫폼 본문 칸에 그대로 붙여넣는 경우
- 시트 맨 앞 `# 제목` 문단이 시트 제목과 같으면 본문에서 뺀다 (제목 넣기와 겹치지 않게)
- 옵션을 바꾸면 미리보기가 바로 바뀌고, "복사했어요/저장했어요" 표시는 지워진다

## size class
- compact: 위 취소 · 제목 / 옵션 → 미리보기 순으로 쌓고 / 아래 막대에 복사·저장 (영어 200% 에서 위 막대가 넘치지 않게)
- medium 이상: 왼쪽 옵션 칸(`pane.sheetList`, 아래에 버튼) + 오른쪽 미리보기
