# export · 내보내기

## 들어오는 길
- 시트 / 폴더 / 작품의 컨텍스트 메뉴 → 내보내기

## 내용
- 범위: 시트 하나 · 폴더 전체(순서대로 이어 붙임) · 작품 전체
- 대상:
  - **연재 플랫폼에 붙여넣기** — 클립보드로. 문단 사이 빈 줄, 들여쓰기, Markdown 기호 제거 규칙을 고른다
  - 파일 — txt · md · docx. epub 은 목록에 "준비 중"으로만 (PRODUCT.md 검토 필요)
- 미리보기: 내보낼 결과를 오른쪽(또는 아래)에 그대로

## 상태
| state | 무엇 |
|---|---|
| `paste` | 붙여넣기용. 규칙 4개(빈 줄 · 첫 줄 들여쓰기(전각 공백) · Markdown 기호 지우기 · 제목 넣기) |
| `file` | 파일. 형식 하나 고르기. 파일은 제목을 넣고 빈 줄로 나눈다. md 만 Markdown 기호를 남기고, docx 미리보기는 제목을 제목 모양으로 |

- 기본값: 빈 줄 ○ · 들여쓰기 ✕ · 기호 지우기 ○ · 제목 ✕ — 연재 플랫폼 본문 칸에 그대로 붙여넣는 경우
- 시트 맨 앞 `# 제목` 문단이 시트 제목과 같으면 본문에서 뺀다 (제목 넣기와 겹치지 않게)
- 옵션을 바꾸면 미리보기가 바로 바뀌고, "복사했어요/저장했어요" 표시는 지워진다

## size class
- compact: 위 취소 · 제목 / 옵션 → 미리보기 순으로 쌓고 / 아래 막대에 복사·저장 (영어 200% 에서 위 막대가 넘치지 않게)
- medium 이상: 왼쪽 옵션 칸(`pane.sheetList`, 아래에 버튼) + 오른쪽 미리보기

## 열린 질문 (PRODUCT.md)

## Mac (0.3.0)
- 들어오는 길: 에디터 도구 · 파일 메뉴 ⌘⇧E · 시트 컨텍스트 메뉴 · 팔레트. 열기 전에 쓰던 글을 저장한다.
- 들어오는 길: 내보내기 창(⌘⇧E) 말고도 시트 메뉴 · 컨텍스트 메뉴 · 팔레트의 "연재처에 붙여넣기용 복사" ⌥⌘C 가 창 없이 이 시트를 **마지막 붙여넣기 규칙**으로 plain text 복사하고 토스트 "복사했어요 · N자".
- 한 창(시트 창)에 왼쪽 옵션 · 오른쪽 미리보기(글자수 함께). 범위 세그먼트(이 시트 · 폴더 전체 · 작품 전체) · 대상 세그먼트(붙여넣기용 · 파일).
- **파일은 txt · md · docx.** epub 은 목록에 없다. md 는 규칙 4개를 숨기고 본문을 쓴 그대로 `---` 로 이어 붙인다.
- **docx**: 제목 줄은 제목 1, 그 밖의 `#` 은 제목 1–3, 장면 전환은 가운데 `* * *`, `**굵게**` · `*기울임*` · `~~취소선~~` 은 서식으로. 글꼴 · 크기 · 줄간격 · 첫 줄 들여쓰기 · 시트 사이 쪽 나눔 · 제목 넣기, "쪽 설정"(여백) 접어 둠. 기본: 맑은 고딕 10pt, 줄간격 160%, A4, 여백 위 20 · 아래 15 · 왼쪽/오른쪽 30mm, 첫 줄 들여쓰기 켬. 미리 보기는 아직 일반 텍스트.
- 이어 붙이기: 시트 사이 빈 줄 둘("\n\n\n"). 작품 전체 = 폴더 순서 · 시트 순서.
- 붙여넣기용 복사는 plain text 만. 파일 저장은 저장 패널(이름 = 시트 제목 · 폴더 이름 · 작품 제목, 금지 문자는 `_`).
- 마지막 선택(범위 · 대상 · 형식 · 규칙)을 기억한다 — 매 회차 같은 방식으로 내보내는 작가를 위해. (검토 필요: 공통 spec 의 "기본값"은 처음 한 번만 적용된다)
- 버튼은 누른 뒤 "복사했어요 / 저장했어요"로 바뀌고, 옵션을 바꾸면 되돌아간다.
