# command-palette · 명령 팔레트

⌘K / Ctrl+K 로 여는 상자 하나. 시트로 바로 가거나 명령을 실행한다. 메뉴를 몰라도 이름으로 찾아 쓰게 한다.

## 어디서
- **데스크톱(Mac · Windows)**: 에디터 상단 명령 버튼, 또는 단축키.
- **iPad · Android 태블릿**: 키보드를 연결했을 때 단축키로만. 버튼은 두지 않는다.
- 폰에는 없다 — 검색 화면이 그 역할을 한다.

## 내용
- 입력이 비었을 때: **최근 시트** 3개 + 명령 전체.
- 입력하면: 시트(제목 · 첫 줄 · 폴더 이름으로 일치) 최대 6개 + 이름이 맞는 명령.
- 명령 목록은 데스크톱 메뉴 막대와 같은 정본에서 나온다 — 새 시트 · 새 작품 · 검색 · 집중 모드 · 시트 정보 · 변경 기록 · 내보내기 · 연재처에 붙여넣기용 복사(⌥⌘C) · 작품 설정 · 환경설정 · 백업 · 단축키.
- 회차 명령: 여기까지 발행 · 회차 번호 다시 매기기 · 외전·공지 표시/해제 · "회차 상태 → 초고/퇴고/예약/발행"(상태 명령은 입력했을 때만 보인다).
- 맞는 게 없으면 "'…'에 맞는 것이 없어요."
- 하단 힌트: Enter 열기 · Esc 닫기. 위아래 화살표로 고른다(네이티브 구현).

## size class
| class | 형태 |
|---|---|
| compact | 화면 전체 (창을 좁힌 데스크톱), 오른쪽 위 닫기 |
| medium 이상 | 위쪽에 뜬 상자(`pane.dialog` 폭), 바깥 scrim 누르면 닫힘 |

## 상태
- `default` — 막 연 상태(빈 입력).
- `query` — 검색어를 넣은 상태(`fixtures` 의 sampleQuery).

## Mac (0.3.0)
- ⌘K 팔레트와 ⌘⇧F 검색이 **같은 상자**다. 검색 모드는 최근 시트 · 명령을 빼고 일치만 보인다(→ search).
- 묶음: 최근 시트(빈 입력, 고친 순 3개) / 시트 · 문장(입력 시, core 검색 — 모든 작품, 열린 작품 먼저, 최대 30개, 다른 작품의 결과를 누르면 그 작품으로 옮겨 연다) / 폴더 / 작품 / 명령.
- 명령: 새 시트 · 새 작품 · 검색 · 집중 모드 · 시트 정보 · 변경 기록 · 내보내기 · 작품 설정 · 환경설정 · 위로 · 아래로 · 휴지통 · 휴지통으로 · 웹 버전에서 가져오기. 시트가 필요한 명령은 시트가 없으면 빠진다. (백업 · 단축키 · 텍스트 폴더 가져오기는 아직 팔레트에 없다.)
- ↑↓ · Tab 으로 고르고, Enter 실행, Esc 닫기. 마우스를 올리면 그 줄이 골라진다.
- 창 위쪽 가운데 `pane.dialog` 폭, 바깥 scrim 누르면 닫힘. compact 폭에서는 전체.
