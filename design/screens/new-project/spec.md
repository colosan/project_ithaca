# new-project · 새 작품

새 작품을 만들고 처음 쓸 준비를 한 번에 끝낸다.

## 들어오는 길
- 라이브러리 맨 아래 ＋ 새 작품 (app-shell)
- 첫 실행 — 작품이 하나도 없을 때 빈 화면 대신 이 화면

## 내용
| 항목 | 기본값 | 비고 |
|---|---|---|
| 제목 | (빈칸) | 필수 |
| 원고 언어 | 늘 한국어 (ADR-0011) | 고르지 않는다 |
| 시트 목표 분량 | 없음 | 나중에 작품 설정에서 바꿀 수 있음 |
| 기본 폴더 | 연재 · 설정 · 자료 | 이름 미리 바꾸기 가능, 체크 해제로 빼기 |

- [만들기] → 첫 폴더(연재)에 빈 시트 하나를 만들고 에디터로 바로 들어간다.

## 상태
| state | 무엇 |
|---|---|
| `default` | 라이브러리에서 연 경우. 취소 가능 |
| `first-run` | 작품이 하나도 없을 때. 환영 문구 · 취소 없음 · 가져오기는 "준비 중" |

- 제목을 쓰기 전엔 [만들기]가 흐리게(`opacity.disabled`) 눌리지 않는다.

## size class
- compact: 전체 화면 (위: 취소 · 제목 · 만들기)
- medium 이상: 가운데 다이얼로그 (`pane.dialog`). first-run 은 앱 대신 사이드바 색 바탕 위에

## 열린 질문
- 작품 템플릿(빈 작품 / 연재용 / 단편용)이 필요한가? → **제안: 지금은 없음** (기본 폴더 체크로 충분, PRODUCT.md 검토 필요)
- 다른 앱(다른 글쓰기 앱 · txt 폴더)에서 가져오기를 여기서 할 것인가?

## Mac (0.3.0)
- 원고 언어는 한국어 하나(ADR-0011). 기본 폴더는 연재 · 설정 · 자료.
- 시트 목표는 체크 + 숫자 + 기준. ko 원고는 기준에 문피아 · 노벨피아가 더 있다.
- 폴더는 하나 이상 켜져 있어야 [만들기]가 눌린다. 첫 폴더(연재)에 빈 시트 하나 — **1화 · 초고** — 를 만들고 연다.
- `first-run`: 작품이 없고 · 쓸 수 있고 · 열면서 건너뛴 작품이 없을 때만. 환영 문구 아래 "쓰던 원고가 있나요?" 칸에 [웹 버전에서 가져오기…] · [텍스트 폴더 가져오기…](→ import), 그 아래 "새로 시작하기". 닫을 수 없고, ⌘Q 는 된다.
- 작품을 지워서 하나도 남지 않으면 다시 `first-run`.

## Mac (0.5.2) — 사용자 피드백으로 바꿈
- 입력은 **제목 · 시트 목표 분량**만. 폴더는 연재 · 설정 · 자료로 만들고 사이드바에서 바꾼다. 원고 언어는 늘 한국어다(ADR-0011).
- `first-run`은 **처음 실행할 때 한 번만** 뜨고, **나중에**(Esc)로 닫을 수 있다. 위 0.3.0의 "닫을 수 없다"를 대체한다.
  - 닫으면, 그리고 작품을 모두 지웠을 때도, 에디터 자리에 "아직 작품이 없어요"와 [새 작품…] · [웹 버전에서 가져오기…] · [텍스트 폴더 가져오기…]가 보인다.
- 글자: 환영 제목은 `title`(20), 폼은 `label` 크기(13)로 macOS 기본 컨트롤과 맞춘다. 전에는 `display`(28)와 `body`(15)를 써서 팝업(13)과 크기가 어긋났다.
