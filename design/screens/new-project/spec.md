# new-project · 새 작품

새 작품을 만들고 처음 쓸 준비를 한 번에 끝낸다.

## 들어오는 길
- 라이브러리 맨 아래 ＋ 새 작품 (app-shell)
- 첫 실행 — 작품이 하나도 없을 때 빈 화면 대신 이 화면

## 내용
| 항목 | 기본값 | 비고 |
|---|---|---|
| 제목 | (빈칸) | 필수 |
| 원고 언어 | UI 언어와 같게 | 분량 단위를 정한다 (ADR-0005) |
| 시트 목표 분량 | 없음 | 나중에 작품 설정에서 바꿀 수 있음 |
| 기본 폴더 | 연재 · 설정 · 자료 | 이름 미리 바꾸기 가능, 체크 해제로 빼기 |

- [만들기] → 첫 폴더(연재)에 빈 시트 하나를 만들고 에디터로 바로 들어간다.

## size class
- compact: 전체 화면 · medium 이상: 가운데 다이얼로그 (`pane.dialog`)

## 열린 질문
- 작품 템플릿(빈 작품 / 연재용 / 단편용)이 필요한가?
- 다른 앱(Ulysses · Scrivener · txt 폴더)에서 가져오기를 여기서 할 것인가?
