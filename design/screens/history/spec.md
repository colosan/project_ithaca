# history · 변경 기록

시트 하나의 전체 이력. **Claude 에게 MCP 로 쓰기 권한을 다 열어 주는 대신, 여기서 모든 걸 보고 되돌릴 수 있어야 한다** (ADR-0002 §6).

## 들어오는 길
- 에디터 메뉴 → 변경 기록
- Claude 가 시트를 고쳤을 때 뜨는 알림 → "보기"

## 내용
- 시간순 블록 목록: 시각 · 기기 · 주체(나 / Claude) · 종류(편집 / 점유 / 합침) · 바뀐 글자수(+120 −34)
- 필터: 전부 · **Claude 가 한 것만** · 이 기기만
- 블록을 고르면 직전과의 문단 diff (branch-resolve 와 같은 강조 규칙)
- [이 시점으로 되돌리기] — 기록을 지우지 않고, 그 시점 내용으로 새 Edit 블록을 쌓는다
- 맨 위에 체인 무결성 표시: "기록 1,204개 · 해시 검증 통과"

## 상태
| state | 무엇 |
|---|---|
| `all` | 모든 기록. 맨 위 기록이 골라진 채로 (wide) |
| `claude` | 필터가 "Claude가 한 것"으로 열린 상태 — Claude 알림의 "보기"가 여기로 |

- 이전 · 이후 두 칸. 바뀐 부분만 강조 (이전: `surface.selected`, 이후: `accent.soft`). 앞뒤 공통 부분은 그대로.
- 점유처럼 글이 안 바뀐 기록은 "글 내용은 바뀌지 않은 기록" 만 보이고 되돌리기가 없다.
- 되돌리기를 누르면 "되돌렸어요 — 새 기록이 추가됐어요" (확인창 없음 — 되돌리기도 되돌릴 수 있으므로).

## size class
- compact: 목록 → 누르면 diff 화면 (push)
- medium 이상: 왼쪽 목록 + 오른쪽 diff

## 열린 질문
- 작품 전체(모든 시트)의 Claude 변경을 한 번에 보는 화면이 따로 필요한가?

## Mac (0.3.0)
- 들어오는 길: 에디터 도구 · 시트 메뉴 ⌘⇧H · 시트 컨텍스트 메뉴 · 팔레트. 열기 전에 쓰던 글을 저장한다. 시트 창(다이얼로그) 하나에 왼쪽 목록 + 오른쪽 이전 · 이후.
- 머리에 무결성 줄("기록 N개 · 해시 검증 통과" 또는 실패 이유) · 필터 세그먼트(전부 · Claude가 한 것 · 이 기기) · 닫기.
- 행: 시각 · 주체(나 / Claude) · 종류(편집 · 점유 · 합침, 회차 정보 같은 메타 변경은 "편집"으로) · +추가 −삭제 글자수 · 기기.
- diff 는 빈 줄을 뺀 줄 단위 비교, 바뀐 줄만 강조.
- 되돌리기는 확인창 없이 새 블록. 저장 못 한 글이 있으면 먼저 저장하고, 커서 자리를 지킨다. 손상된 시트에서는 되돌리기가 막힌다(→ damaged-sheet).
- Claude 쓰기 도구가 아직 없어서 "Claude가 한 것" 필터는 **숨긴다**(ADR-0007, 2026-10-24) — 쓰기 도구가 생기면 되살린다(ADR-0009 §7). Claude 알림의 "보기" 경로도 아직 없다.

## Mac (0.5.3) — 작업 단위로 묶기
- 왜: 자동 저장이 타자를 1.5초 멈출 때마다 블록 하나를 쌓는다. 한 시간 쓰면 기록이 수백 개라 목록이 쓸모없었다. 블록을 덜 쓰면 그만큼 글을 잃을 수 있으므로 저장 주기는 그대로 두고, **보여 줄 때 묶는다**(형식 · 블록은 그대로, FORMAT 변경 없음).
- **작업(session)**: 같은 기기 · 같은 주체(나 / Claude)의 편집이 바로 앞 저장 위에 이어 쌓이고 사이가 10분 미만이면 한 작업. 점유 · 합침은 각자 한 줄. 분기 사본처럼 앞 저장에 이어지지 않는 블록은 새 작업. 묶는 규칙은 core `history_sessions` 하나 — 다른 플랫폼도 같은 규칙을 쓴다.
- 목록: 날짜 머리(오늘 · 어제 · "10월 4일 (일)") 아래 작업 한 줄씩, 최신 먼저. 줄: 시간 범위("19:53 – 20:25", 저장 하나면 한 시각) · **순변화** +N −M(작업 전 글 → 작업 후 글. 썼다 지운 문장은 세지 않는다) · 둘째 줄 "나 · 기기 · 저장 9번".
- 저장이 둘 이상인 작업만 펼침 단추(›). 펼치면 그 작업의 저장 시점들이 시각 · +추가 −삭제(그 저장 하나의 변화)로 들여 보인다. 지금 글인 저장에는 ✓.
- 오른쪽: 작업을 고르면 "작업 전체 · 범위" — 작업 전 글과 작업 끝 글의 비교. 저장 시점을 고르면 "{시각}에 저장된 시점" — 그 저장 직전과의 비교. 이전 칸은 시간순 이웃이 아니라 그 블록의 실제 부모(작업의 `base`)라서 분기가 있어도 맞다.
- 되돌리기: 작업이면 작업이 끝난 시점의 글, 저장 시점이면 그 시점의 글로. 예전과 같이 새 블록, 확인창 없음. 지금 글과 같은 시점은 막힌다.
- 머리의 "기록 N개"는 그대로 블록 수(무결성 검증 대상).
- **이름 붙인 버전("이 버전 표시")은 하지 않았다**: 블록에 이름을 담을 칸이 없어서 새 블록 종류나 toc 필드가 필요하다 → 형식 판 올림 · 마이그레이션(ADR-0008) 감. 따로 결정할 일.
