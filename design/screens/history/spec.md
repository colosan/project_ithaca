# history · 변경 기록

시트 하나의 전체 이력. **Claude 에게 MCP 로 쓰기 권한을 다 열어 주는 대신, 여기서 모든 걸 보고 되돌릴 수 있어야 한다** (ADR-0002 §6).

## 들어오는 길
- 에디터 메뉴 → 변경 기록
- Claude 가 시트를 고쳤을 때 뜨는 알림 → "보기"

## 내용
- 시간순 블록 목록: 시각 · 기기 · 주체(나 / Claude) · 종류(편집 / 점유 / 합침) · 바뀐 글자수(+120 −34)
- 필터: 전부 · **Claude 가 한 것만** · 이 기기만
- 블록을 고르면 직전과의 문단 diff (branch-resolve 와 같은 강조 규칙)
- [이 시점으로 되돌리기] — 기록을 지우지 않고, 그 시점 내용으로 새 Edit 블록을 쌓는다
- 맨 위에 체인 무결성 표시: "기록 1,204개 · 해시 검증 통과"

## 상태
| state | 무엇 |
|---|---|
| `all` | 모든 기록. 맨 위 기록이 골라진 채로 (wide) |
| `claude` | 필터가 "Claude가 한 것"으로 열린 상태 — Claude 알림의 "보기"가 여기로 |

- 이전 · 이후 두 칸. 바뀐 부분만 강조 (이전: `surface.selected`, 이후: `accent.soft`). 앞뒤 공통 부분은 그대로.
- 점유처럼 글이 안 바뀐 기록은 "글 내용은 바뀌지 않은 기록" 만 보이고 되돌리기가 없다.
- 되돌리기를 누르면 "되돌렸어요 — 새 기록이 추가됐어요" (확인창 없음 — 되돌리기도 되돌릴 수 있으므로).

## size class
- compact: 목록 → 누르면 diff 화면 (push)
- medium 이상: 왼쪽 목록 + 오른쪽 diff
