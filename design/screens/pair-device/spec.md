# pair-device · 기기 추가

새 기기를 내 기기 묶음에 넣는다. 이때 E2E 암호화 키를 나누므로, 서버(relay)는 내용을 볼 수 없다.

## 들어오는 길
- 환경설정 → 동기화 → ＋ 기기 추가

## 흐름
1. 이미 쓰던 기기: **QR + 6자리 코드**를 띄운다 (2분 유효)
2. 새 기기: 카메라로 QR 을 찍거나 코드를 입력
3. 양쪽에 같은 확인 단어 4개를 보여주고 "같다"를 누르면 연결 — 중간자 방지
4. 첫 동기화 진행률 (시트 수 · 용량)

## 상태
| state | 무엇 |
|---|---|
| `show-code` | 쓰던 기기. QR(`size.pair.qr`) · 6자리 코드 · 남은 시간 · 새 기기에서 할 일 3단계 |
| `enter-code` | 새 기기. 6칸(`size.pair.codeCell`, 좁으면 줄어듦) — 6자리가 차면 바로 확인으로. 모바일만 [카메라로 QR 찍기] |
| `confirm` | 확인 단어 4개. [같아요] → 동기화 · [달라요] → 취소 안내 후 처음부터 |
| `syncing` | 시트 수 · 용량 · 진행 막대. 닫아도 이어서 받는다. [완료] → 환경설정 · 동기화 |

- 프로토타입의 [새 기기가 찍었다고 치기]는 workbench 에서 흐름을 넘기기 위한 것 — 실제 앱엔 없다(상대 기기가 찍으면 자동으로 넘어간다).
- QR 은 테마와 상관없이 밝은 바탕에 어두운 점이어야 한다. 프로토타입은 토큰 색을 써서 다크에서 뒤집혀 보인다 — 네이티브는 고정 흰 판 위에 그린다.

## size class
- 카메라가 있는 쪽(모바일)은 스캐너가 기본, 데스크톱은 QR 표시가 기본
- compact: 전체 화면 · medium 이상: 환경설정 위 다이얼로그(`pane.dialog`)

## 열린 질문
- 데스크톱 ↔ 데스크톱(카메라 없음)은 코드 입력만으로 충분한가?
- 기기 빼기(분실) 시 키를 바꾸는 흐름이 필요하다 — 별도 화면?
