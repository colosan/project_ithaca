# search · 검색

설정 이름, 복선, 지난 회차의 문장을 빨리 찾는다.

## 들어오는 길
- 단축키 (Mac ⌘F · Windows Ctrl+F · 모바일 상단 돋보기)
- 라이브러리 상단 검색 칸

## 내용
- 범위: 이 폴더 · 이 작품 · 모든 작품
- 결과는 시트 단위로 묶고, 시트마다 일치한 문단을 2–3개 미리보기(일치 부분 강조)
- 결과를 누르면 그 시트의 그 문단으로 스크롤

## 상태
| state | 무엇 |
|---|---|
| `empty` | 검색어 없음. 최근 검색 3개 — 누르면 다시 찾는다 |
| `results` | 일치한 시트 목록 · 시트마다 일치 문단 2개 · 일치 부분 `accent.soft` 강조 |
| `none` | 결과 없음 + "범위를 넓혀 보세요" |

- 범위 칩은 결과를 바로 다시 계산한다. 검색어를 입력하는 대로 찾는다 (엔터 없음).

## size class
- compact: 전체 화면 결과 목록 → 누르면 에디터
- medium 이상: **시트 목록 자리를 결과 목록이 대신한다**(Ulysses 방식). 에디터 자리에 고른 시트 미리보기(강조 포함), ↗ 로 열기

## 열린 질문
- 바꾸기(replace)까지 넣을 것인가? 넣는다면 hash chain 상 한 번의 Edit 블록으로 묶는다. → **제안: v1 은 찾기만** (PRODUCT.md 검토 필요)
- 한글 초성 검색(ㄷㅇㅈㄱ → 등대지기)이 필요한가?

## Mac (0.3.0)
- ⌘⇧F(편집 메뉴) · 시트 목록 머리의 돋보기 → 명령 팔레트와 같은 상자의 검색 모드(command-palette). 시트 목록 자리를 대신하는 결과 목록 · 미리보기는 아직 없다.
- 범위 칩 없음 — **모든 작품**을 찾고 열린 작품을 먼저 보인다(작품당 최대 200, 전체 500, 보이는 것은 30). 대소문자 무시 · 그대로 일치.
- 일치 하나가 결과 하나(시트마다 묶지 않음): 제목 + 같은 줄의 앞뒤 문맥(일치 부분 강조). 누르면 그 작품 · 시트를 열고 일치 부분을 고른 채 가운데로.
- ⌘F 는 시트 안에서 찾기(시스템 찾기 막대).
- 최근 검색 · `none` 의 "범위를 넓혀 보세요"는 없다 — 결과가 없으면 "'…'에 맞는 것이 없어요."
