# search · 검색

설정 이름, 복선, 지난 회차의 문장을 빨리 찾는다.

## 들어오는 길
- 단축키 (Mac ⌘F · Windows Ctrl+F · 모바일 상단 돋보기)
- 라이브러리 상단 검색 칸

## 내용
- 범위: 이 폴더 · 이 작품 · 모든 작품
- 결과는 시트 단위로 묶고, 시트마다 일치한 문단을 2–3개 미리보기(일치 부분 강조)
- 결과를 누르면 그 시트의 그 문단으로 스크롤

## size class
- compact: 전체 화면 결과 목록 → 누르면 에디터
- medium 이상: **시트 목록 자리를 결과 목록이 대신한다**(Ulysses 방식). 에디터는 그대로
