# search · 검색

설정 이름, 복선, 지난 회차의 문장을 빨리 찾는다.

## 들어오는 길
- 단축키 (Mac ⌘F · Windows Ctrl+F · 모바일 상단 돋보기)
- 라이브러리 상단 검색 칸

## 내용
- 범위: 이 폴더 · 이 작품 · 모든 작품
- 결과는 시트 단위로 묶고, 시트마다 일치한 문단을 2–3개 미리보기(일치 부분 강조)
- 결과를 누르면 그 시트의 그 문단으로 스크롤

## 상태
| state | 무엇 |
|---|---|
| `empty` | 검색어 없음. 최근 검색 3개 — 누르면 다시 찾는다 |
| `results` | 일치한 시트 목록 · 시트마다 일치 문단 2개 · 일치 부분 `accent.soft` 강조 |
| `none` | 결과 없음 + "범위를 넓혀 보세요" |

- 범위 칩은 결과를 바로 다시 계산한다. 검색어를 입력하는 대로 찾는다 (엔터 없음).

## size class
- compact: 전체 화면 결과 목록 → 누르면 에디터
- medium 이상: **시트 목록 자리를 결과 목록이 대신한다**(Ulysses 방식). 에디터 자리에 고른 시트 미리보기(강조 포함), ↗ 로 열기
