# app-shell · 앱 뼈대 (라이브러리 / 시트 목록 / 에디터)

## 목적
작품 / 원고 목록 / 에디터 3단이 size class 에 따라 어떻게 접히는지 정한다. 모든 화면이 이 뼈대 위에 선다.

## 데이터 구조 (PRODUCT.md)
작품(project) → 폴더 → 시트. 새 작품의 기본 폴더는 **연재 · 설정 · 자료**. 폴더 이름은 사용자가 바꾸고 지우고 새로 만든다.
시트는 지금은 전부 자유 본문(Markdown). 폴더별 템플릿은 나중.

## size class 별 레이아웃

| class | 보이는 pane | 숨은 pane 여는 법 | 인스펙터 |
|---|---|---|---|
| compact | 에디터 하나 | 상단 ‹ 폴더 → 시트 목록 → 라이브러리 (push) | 아래에서 올라오는 시트 (55%) |
| medium | 시트 목록 + 에디터 | 상단 라이브러리 버튼 → overlay | 오른쪽 overlay |
| expanded | 라이브러리 + 시트 목록 + 에디터 | — | 오른쪽 overlay |
| large | expanded 와 같음 | — | 오른쪽에 붙음 (`pane.inspector`) |

> **웹 앱에서 써보고 바꾼 규칙 (2026-10-23, 검토 필요 · ADR-0007)** — 위 표대로면 840px 에서 에디터 글줄이 204px, 1200px 에서 인스펙터를 붙이면 212px 로 쓸 수 없을 만큼 좁다.
> 그래서 pane 은 **에디터가 600 이상 남을 때만 붙는다.** 우선순위는 에디터 → (열려 있으면) 인스펙터 → 시트 목록 → 라이브러리. 인스펙터는 에디터 580까지 허용 — 원고 옆에서 설정을 읽는 게 목적이라서. 못 붙는 pane 은 overlay(바깥 누르면 닫힘)로 연다.
> 결과(인스펙터 닫힘): 600–899 에디터만(목록 · 라이브러리 overlay) · 900–1139 목록 + 에디터 · 1140 이상 3단. 인스펙터를 열면 900 이상에서 붙고, 남는 폭만큼 목록 · 라이브러리가 접힌다.
> 확정되면 위 표와 `layout.json` 을 이 규칙으로 고친다.

- 에디터 본문 폭은 `editor.measure` 에서 멈춘다.
- 라이브러리: 작품 목록, 열린 작품만 펼쳐서 폴더(이름 · 시트 수). 열린 작품 줄을 다시 누르면 접히고 펼쳐진다(0.5.2). 폴더 목록 끝에 ＋ 새 폴더, 그 아래 **휴지통**(→ trash). 맨 아래 ＋ 새 작품 · 환경설정.
- 시트 목록 행: 제목 · 첫 줄 · 셋째 줄(회차 · 상태 · 예약일 · **올릴 본문** 글자수). 고친 시각은 행에 두지 않고 툴팁 · 인스펙터로. 어느 언어든 3줄을 넘지 않는다(긴 회차 표시는 말줄임). 갈라진 사본은 `branched`(git-branch, 주황), 손상은 `damaged`(file-warning, 빨강) — 모양으로도 가른다 (ADR-0002). 제목이 빈 시트는 "제목 없음".
- 시트 목록 머리의 ＋ 는 무엇을 만들지 고르는 선택 창(빈 시트 · 인물 · 장소 · 집단 · 용어 → story-bible §1). 빈 시트는 그 폴더 맨 아래(다음 회차 자리)에 만들고 바로 연다. ⌘N 은 고르지 않고 바로 빈 시트. 시트 순서는 작가가 정한다(끌기 · ⌘⌥↑↓). 빈 시트의 에디터는 "첫 줄이 제목이 돼요" 자리표시.

## 에디터 상단 도구
왼쪽부터 (compact: ‹ 폴더 / medium: 라이브러리) … 명령 팔레트(데스크톱만) · 집중 모드 · 변경 기록 · 내보내기 · 인스펙터.

## 인스펙터 (오른쪽 패널)
수동으로 연다. 탭 셋:
- **참조** — 설정 폴더의 시트를 원고 옆에 띄운다 (PRODUCT.md "설정 참조").
- **정보** — 회차 상태 · 예약일 · 연재처(예약 · 발행일 때, 작은 입력 칸) 다음에 **올릴 본문** 묶음(공백 포함 · 제외 · 문피아 · 노벨피아)을 위에 모아 두고, 그 아래 원고 전체(공백 포함, 제목 · 기호 포함) · · ko 원고면 **원고지 매수**(200자), en 원고면 단어 수 · 문단 수 · 읽는 시간(ko 500자/분 · en 230단어/분) · 만든 날 · 고친 날.
- **개요** — 시트의 제목(#)과 문단 첫 줄 목록. 누르면 그 문단으로 간다.

## 집중 모드
- 라이브러리 · 시트 목록 · 인스펙터를 모두 닫고 에디터만. 상단에는 "집중 모드 끝내기"만 남는다.
- 커서가 있는 문단(환경설정에서 문장으로 바꿀 수 있음)만 그대로, 나머지는 `opacity.focusDim`.
- 하단 분량 표시는 남긴다 — 연재 작가에게 분량은 집중을 깨지 않는 정보다.

## 분량 표기 (하단)
- 항상 **공백 포함 · 공백 제외** 글자수 둘 다. (예전에 만든 en 원고만 단어 수, ADR-0011)
- 숫자는 **올릴 본문** 기준: core `platform_body`(제목 줄 · Markdown 기호 제외, 장면 구분 정규화)를 `count_for` 로 센다. 툴팁이 정의와 원고 전체 글자수를 알려 준다. 목표 진행도 같은 기준(PRODUCT 2026-10-24).
- 저장 상태 아이콘은 디스크(`savedLocal`) — 구름 아님. 툴팁: "원고는 이 Mac에만 저장돼요" + 마지막 백업 시각.
- 작품 설정에 목표가 있으면 하단 위에 진행 막대 + "목표 5,000 · 96%". 기준(공백 포함/제외/단어)은 작품 설정에서 고른다.
- 오른쪽 끝에 저장 · 동기화 상태("저장됨"). 문제가 생기면 이 자리에 경고가 뜬다.
- 일일 목표 · 연속 기록은 만들지 않는다.

## 상태
- `default` — 연재 폴더의 시트 편집 중.
- `readonly` — 다른 기기가 점유 중(ADR-0002). 경고 띠 + [점유하기], 본문 `opacity.readOnly`.
- `reference` — 인스펙터를 참조 탭으로 연 상태.
- `info` — 인스펙터를 정보 탭으로 연 상태.
- `focus` — 집중 모드.

## 플랫폼 관례 (프로토타입에서 흉내 내지 않음)
- 상단 바 · 뒤로 제스처 · 사이드바 토글 · 컨텍스트 메뉴(폴더 이름 바꾸기 · 삭제 · 시트 휴지통으로)는 각 OS 기본을 따른다.
- 데스크톱 메뉴 막대(파일 · 편집 · 보기 · 서식 · 시트 · 창 · 도움말)는 명령 팔레트와 같은 명령 목록으로 만든다.

## Mac (0.3.0)
실제 앱(swift/Sources/IthacaMac)이 하는 것. 위 공통 spec 과 다른 곳만 적는다.

**접기** — 위 "웹 앱에서 써보고 바꾼 규칙"을 그대로 쓴다(에디터 600 이상, 인스펙터는 580까지). compact 폭에서는 에디터 하나 + overlay. 붙지 못한 pane 은 scrim 위 overlay, 바깥을 누르면 닫힌다.

**라이브러리**
- 작품 순서 = 이 라이브러리에 더한 순서(가져오기 · 사본 복원은 맨 아래). 열린 작품만 펼친다.
- 작품 컨텍스트 메뉴: 작품 설정. 폴더 컨텍스트 메뉴: 폴더 정보(인스펙터 · 폴더 통계) · 이름 바꾸기(제자리 입력) · 삭제.
- 시트를 폴더 행에 끌어 놓으면 그 폴더 맨 아래로 옮긴다.
- 맨 아래 ＋ 새 작품 · 환경설정(톱니).

**시트 목록**
- 머리: 폴더 이름 / "시트 12개 · 29,822자"(en 은 단어) / 회차가 있으면 "비축 3화 · 다음 연재 10/26". 긴 문구는 툴팁. 머리를 누르면 인스펙터에 폴더 통계(→ episodes). 오른쪽 검색 · ＋.
- 행: 제목(빈 제목은 "제목 없음", `ink.tertiary`) · 첫 줄 · 셋째 줄 "3화 · 초고 · 4,812자 · 10월 24일 18:30". 손상 ⚠ `state.danger`(→ damaged-sheet), 갈라짐 ⚠ `state.warning`.
- 마우스를 올린 행 · 열린 행에 휴지통 버튼. 끌어서 순서 바꾸기(놓을 자리에 `accent.primary` 선), 마지막 행 아래에 놓으면 맨 끝.
- 컨텍스트 메뉴: 위로 · 아래로 · 다른 폴더로 옮기기 · (회차) 여기까지 발행으로 표시 · 외전·공지로 표시 · 변경 기록 · 내보내기… · 휴지통으로.
- ＋ 는 폴더 끝의 빈 시트가 이미 있으면 새로 만들지 않고 그것을 연다(빈 시트가 쌓이지 않게). 첫 폴더의 새 시트는 회차 "초고".

**에디터**
- 도구: (목록이 안 붙었을 때) 라이브러리 · … · 명령 팔레트 · 집중 모드 · 변경 기록 · 내보내기 · 인스펙터. 시트가 없으면 변경 기록 · 내보내기는 숨김.
- 본문 위 띠(위에서부터): 읽기 전용(→ library-error) · 열면서 찾은 문제(닫기) · 목차 손상 · 시트 손상(→ damaged-sheet).
- 자동 저장: 입력을 1.5초 멈추면. 한글 조합 중에는 기다린다. 시트 바꾸기 · 앱 비활성 · 종료 때 바로 저장. 실패하면 2 · 5 · 15 · 30 · 60초 간격으로 다시 시도.
- **저장 실패 시 글을 버리지 않는다.** 시트 바꾸기 · 지우기 · 종료가 막히고 경고창: 다시 시도 · 글 복사 · 파일로 내보내기… · (종료 중) 그래도 종료(한 번 더 확인) · 취소.
- 마지막으로 연 작품 · 폴더 · 시트, 작품별 마지막 시트, 시트별 커서 위치를 기억한다.
- 한글은 어절 단위 줄바꿈. 단, 띄어쓰기 없이 16자 넘게 이어진 덩어리가 있는 문단은 글자 단위로 끊는다 — 통째로 다음 줄로 넘어가면 앞에 친 공백이 줄바꿈처럼 보인다 (0.6.7). undo 는 낱자가 아닌 단어 단위. 클립보드는 plain text 만(붙여넣기 · 복사 모두).

**하단**: ko 원고 "공백 포함 · 공백 제외", en 원고 "단어 · 공백 포함". 목표가 있으면 위에 진행 막대 + "목표 5,000 · 96%"(문피아 · 노벨피아 기준이면 붙여넣을 본문으로 셈). 오른쪽 "저장됨" / "저장 중" / "저장하지 못했어요 — 이유" + [다시 시도] (성공할 때까지 남는다).

**인스펙터**
- 참조: 작품의 아무 시트(열린 시트 제외)를 고른다. 기본은 둘째 폴더(설정)의 첫 시트, 고른 것은 기억.
- 정보: 시트 / 폴더 세그먼트. 시트 — 회차 상태 · 예약일 · 공백 포함 · 제외 · 원고지 매수(ko) 또는 단어(en) · 문단 · 읽는 시간 · 만든 날 · 고친 날 · (ko) 연재처 기준 문피아(글자 · 쪽) · 노벨피아. 폴더 — episodes spec.
- 개요: 제목(#)과 문단 첫 줄. 누르면 그 자리로 커서.

**토스트**: 도구 막대 아래 오른쪽(쓰는 줄을 가리지 않게). 6초, 마우스를 올리면 멈춤. 되돌리기가 없는 알림 · 오래 남는 알림(가져오기 결과 · 작품 삭제 · 형식 변환)엔 닫기.

## Mac (0.5.3) — 단축키 · 서식 · 특수문자
- 시스템 서식 메뉴(서체 · 리치 텍스트 굵게)는 평문 원고에서 아무것도 하지 않아 **Markdown 기호를 넣는 서식 메뉴**로 바꾼다.
  - ⌘B `**` · ⌘I `*` · ⌘⇧X `~~`: 선택을 감싸고, 이미 감싸져 있으면 푼다. 되돌리기는 한 번에 한 동작. 여러 줄을 고르면 줄마다 따로 감싼다(강조는 줄을 넘지 못한다 · 제목 `#` · 인용 `>` 표시와 장면 구분은 밖에 둔다, 0.7.1).
  - ⌥⌘1–3 제목 · ⌥⌘0 본문(같은 제목 수준을 다시 누르면 본문) · ⌥⌘' 인용 · ⌘⇧↩ 장면 전환.
  - 굵게는 굵은 서체로, 기울임은 기울여서(Pretendard에 이탤릭이 없음), 취소선은 줄을 그어 보여준다. 기호는 흐리게 그대로 남는다.
- ⌘/ 특수문자 메뉴: 커서 위치에 뜨고 1–9 · 0으로 자주 쓰는 10개를 바로 넣는다. 괄호류는 선택을 감싼다.
- 기본 단축키: ⌘S 지금 저장 · ⌘G/⌘⇧G 다음/이전 찾기 · ⌘[ / ⌘] 이전/다음 시트 · ⌘+ / ⌘- / ⌘0 글자 크기.
- 검토 필요: 단축키 바꾸기(환경설정)는 아직 없다. "..." → "…" 같은 자동 바꾸기는 플랫폼마다 쓰는 기호가 달라 기본으로 켜지 않았다.

## Mac (0.6.0) — 에디터 편의 (story-bible spec §7)
환경설정 › 에디터에서 켠다. 모두 기본 꺼짐.
- **첫 줄 들여쓰기**: 문단 첫 줄을 1em 들여 그린다(`firstLineHeadIndent`, 원고 글자는 그대로). 제목 · 장면 전환 줄 · 맨 앞 `---` front matter 블록은 들이지 않는다.
- **괄호 · 따옴표 짝**: `"` `“` `「` `『` `(` `[` `《` `〈` `【` 를 치면 닫는 짝을 넣고 커서를 사이에. 고른 글이 있으면 감싼다(한 번에 되돌림). 닫는 짝은 뒤가 비었거나 공백 · 다른 닫는 짝일 때만 넣는다(낱말 앞에서는 여는 것만). `"` 는 글자 뒤에서는 닫는 따옴표로 보고 짝을 넣지 않는다. 넣은 짝 바로 앞에서 닫는 짝을 치면 넘어가고, 빈 짝에서 ⌫ 는 둘 다 지운다.
- **줄임표 자동**: `...` → `…` 또는 `……`.
- **시스템 텍스트 대치**: macOS 키보드 › 텍스트 대치 목록을 원고에 적용(NSTextView 표준).
- 한글 조합 중(marked text)에는 아무것도 하지 않는다 — 조합을 끝내는 입력에도. 자동으로 바꾼 것은 친 글자와 **따로 되돌림 한 단계**: ⌘Z 를 한 번 누르면 친 그대로(`(` · `...`)로 돌아온다.
- **특수문자 목록**: ⌘/ 메뉴와 서식 › 특수문자가 환경설정의 순서를 따른다(1–9 · 0 도). 직접 더한 것은 이름 없이 글자만 보인다.

## Mac (0.5.7) — 메뉴 막대 다듬기
- 메뉴 항목 · 팔레트 명령 · 환경설정 → 단축키 표가 **한 목록(`AppCommand`)** 에서 이름 · 단축키 · 쓸 수 있는 조건을 가져온다. 셋이 어긋날 수 없다.
- **⌘⌫**: 글(원고 · 입력 칸) 안에서는 macOS 기본대로 **줄 앞까지 지우기**. 시트를 휴지통으로 보내는 것은 글 밖(목록 등)에서 누를 때만. 이전에는 쓰다가 ⌘⌫를 누르면 시트가 휴지통으로 갔다.
- **⌘=** 도 글자 크게(메뉴 표기는 ⌘+). 다른 Mac 앱과 같다.
- **도움말** 메뉴: 기본 "도움말을 사용할 수 없음" 대신 **Ithaca 도움말**(GitHub 의 `docs/mac-app.md`) · **단축키 보기**(환경설정 → 단축키 탭).
- 창 메뉴(최소화 ⌘M · 확대/축소) · 닫기 ⌘W · 가리기 ⌘H · 실행 취소/다시 실행 · 모두 선택 · 이모지와 기호 · 전체 화면 ⌃⌘F 는 시스템 것을 그대로 쓴다.
- 에디터만 보기 ⌘3: 라이브러리 · 목록 · 인스펙터만 숨기고 글은 흐리지 않는다. 상단에 "양옆 창 다시 보기". ⌘3 · Esc · ⌘1 · ⌘2 로 돌아온다. 집중 모드(⌘⇧D)는 여기에 현재 문단 밖을 흐린다.

## Mac (0.5.7) — 사이드바 · 목록 탐색
- **시트 목록 키보드**: 목록이 키보드를 받고 있을 때. ↑↓ 위·아래 시트 열기 · Home/End · Return · Tab · → 에디터로 · Delete 휴지통으로 · 글자를 치면 그 글자로 시작하는 제목으로(1초 안에 이어 친 글자는 이어 붙임, 한글 자음 ㄷ 은 다·도… 로 시작하는 제목에 맞음). 행을 두 번 누르면 열고 바로 에디터로.
  - 행을 한 번 누르면 전처럼 에디터가 키보드를 받아 바로 쓸 수 있다(쓰는 흐름을 바꾸지 않는다). 검토 필요: 누르면 목록이 키보드를 받게 할지.
- **⌘⌫**: 에디터 · 입력 칸에서는 줄 앞까지 지우기(macOS 기본), 목록에서는 휴지통으로.
- **끌기**: 시트를 끄는 값은 Ithaca 전용 형식 — 원고나 다른 앱에 놓아도 id 글자가 들어가지 않는다. 폴더 행에 끌면 그 행이 강조된다.
- **시트 컨텍스트 메뉴**: 새 시트 · 복제(바로 아래, 회차였으면 번호 없는 초고) · 위로 · 아래로 · 다른 폴더로 옮기기 · 회차 상태 ▸ · 여기까지 발행 · 외전·공지 · 변경 기록 · 붙여넣기용 복사 · 내보내기… · 휴지통으로.
- **폴더**: 두 번 누르거나 컨텍스트 메뉴 → 제자리 이름 바꾸기(Esc 취소, 다른 곳을 누르면 저장). 메뉴: 새 시트 · 폴더 정보 · 이름 바꾸기 · 새 폴더 · 삭제…(마지막 폴더면 없음). 새 폴더는 만들자마자 선택된다. 열린 시트가 든 폴더를 지우면 다음 폴더의 첫 시트를 연다. [되돌리기]는 그 폴더를 다시 보여준다.
- **작품 컨텍스트 메뉴**: 이름 바꾸기(제자리) · 새 폴더(열린 작품) · 작품 설정… · 작품 지우기…. 열려 있지 않은 작품을 지워도 지금 작품은 그대로.
- **빈 폴더**: "아직 시트가 없어요." 아래 ＋ 와 같은 선택 목록.
- **overlay**: Esc 로 닫힌다(라이브러리 · 목록 먼저, 그다음 인스펙터). 한글 조합 중 · 입력 칸 편집 중 · 대화상자가 떠 있으면 Esc 를 가로채지 않는다. 휴지통 행을 눌러도 목록이 붙어 있으면 overlay 가 닫힌다.
- 아직 없음(검토 필요): 여러 시트 고르기, 폴더 순서 끌기(core 에 API 없음), 다른 작품으로 시트 옮기기.

## Mac (0.5.7) — 에디터 기본 동작
- 오른쪽 클릭 메뉴는 시스템 것 그대로(오려두기 · 복사 · 붙여넣기 · 찾아보기 · 맞춤법 · 대체 · 말하기 · 공유)에서 평문 원고에 맞지 않는 **서체**(서체 · 색상 패널)와 **레이아웃 방향**(세로쓰기는 지원하지 않음)만 뺀다. 글 아래 빈 종이에서도 같은 메뉴가 뜬다.
- 끌어다 놓기는 글(평문 · RTF · HTML · URL · 파일 경로)만 받는다. 색 · 서체 · 이미지는 받지 않는다(평문 원고에 남는 것 없이 속성만 묻었다). 놓은 글의 줄바꿈은 \n.
- 여러 군데 선택(⌥ 끌기)을 오려두면 모든 선택이 한 번에, 되돌리기 한 번으로.
- 타자기 스크롤: 켜고 끄면 마지막 줄 아래 여백(화면 절반 / 40%)이 바로 바뀐다. 가운데 맞추기는 **커서**만 따라간다 — 마우스로 끌거나 ⇧ 화살표로 선택을 늘리는 동안에는 화면을 옮기지 않는다.
- 집중 모드 · 에디터만 보기에서 Esc 는 그 모드를 끝낸다(한글 조합 중이면 조합이 먼저). 아니면 시스템 동작(단어 완성) 그대로.
- Home · End 는 커서를 줄 처음 · 끝으로, Page Up · Page Down 은 커서를 한 화면씩 옮긴다(⇧ 는 선택을 늘린다). Mac 기본(화면만 이동)과 다르다 — Windows · 한글에서 온 작가가 기대하는 동작. 문서 처음 · 끝은 ⌘↑ · ⌘↓.
- Markdown 기호 "숨기기" 에서도 줄 앞 기호(`- ` · `> ` · `1. `)는 흐리게 보인다 — 대사 앞 `- ` 는 원고의 일부다. 숨는 것은 `**` · `*` · `~~` · `#` 뿐.

## 작은 창 (⌘4, Mac 0.6.3)
- 보기 메뉴 · 에디터 도구 막대의 글자 버튼 [작은 창](집중 · 에디터만 보기 중에도 보인다, 0.6.4) · ⌘4: 창이 작은 메모처럼 줄어 화면 오른쪽 위에 붙고(360×480, 다음부터는 마지막 자리 · 크기), 보통 창이라 다른 창에 가려진다(0.6.5, 소유자: 늘 위에 떠 있는 것보다 낫다). 쓰던 시트 그대로, 에디터만.
- 위 막대: 시트 제목 · [크게 보기]. 아래: 글자수 · 저장 상태. ⌘[ ⌘] 로 시트 넘기기는 그대로.
- 다시 ⌘4 또는 [크게 보기]: 원래 크기 · 자리로. 앱을 끄면 그 상태로 다시 열린다.
- 결정: 따로 창을 띄우지 않고 같은 창을 줄인다(같은 글을 두 곳에서 고치는 일이 없게). "항상 위" 켜고 끄기 같은 선택지는 두지 않는다. 보통 창이라 미션 컨트롤 · ⌘` 에도 그대로 나온다.

## 원고와 빈 페이지 · 작가의 말 (Mac 0.8.0, ADR-0012)
- 새로 만들기(＋ · 빈 폴더): **원고**(맨 위, ⌘N, "5화 · 본문 아래 작가의 말 칸이 있어요") · **빈 페이지**("메모 · 구상 · 형식 없이 무엇이든") · 설정 항목 넷. 숫자 1–6. 파일 메뉴에도 "빈 페이지".
- 원고 = 회차 정보가 있는 시트, 빈 페이지 = 없는 시트. 회차 상태 선택(정보 탭 · 목록 메뉴)의 첫 항목이 "빈 페이지"다 — 고르면 빈 페이지, 초고 등을 고르면 원고.
- 작가의 말 = `## 작가의 말` 줄부터 끝. 에디터는 그 부분을 본문 아래 상자(`surface.list` 바탕 · `line.subtle` 테두리 · 위로 1.5줄 띄움)에 `ink.secondary` 글로 보이고, 제목 줄은 설정 항목 칸 제목처럼 작게. 제목 줄 오른쪽에 [작가의 말 복사](ghost).
- 작가의 말이 없는 원고는 마지막 줄 아래 [＋ 작가의 말](ghost): 빈 줄 하나 두고 `## 작가의 말` 을 붙이고 커서를 그 아래로. 되돌리기 한 번에 사라진다. 빈 페이지 · 설정 항목 · 읽기 전용에는 없다.
- 하단 글자수 · 목록 · 폴더 통계 · 붙여넣기용 복사 · 내보내기는 작가의 말을 뺀다. "작가의 말 복사"(시트 메뉴 · 목록 메뉴 · 팔레트 · 상자 버튼)는 작가의 말만 붙여넣기 규칙으로 복사하고 "작가의 말을 복사했어요 · N자". 없거나 비었으면 "이 원고에는 작가의 말이 없어요."
