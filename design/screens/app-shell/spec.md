# app-shell · 앱 뼈대 (라이브러리 / 시트 목록 / 에디터)

## 목적
Ulysses 식 3단 구조가 size class 에 따라 어떻게 접히는지 정한다. 모든 화면이 이 뼈대 위에 선다.

## 데이터 구조 (PRODUCT.md)
작품(project) → 폴더 → 시트. 새 작품의 기본 폴더는 **연재 · 설정 · 자료**. 폴더 이름은 사용자가 바꾸고 지우고 새로 만든다.
시트는 지금은 전부 자유 본문(Markdown). 폴더별 템플릿은 나중.

## size class 별 레이아웃

| class | 보이는 pane | 숨은 pane 여는 법 | 인스펙터 |
|---|---|---|---|
| compact | 에디터 하나 | 상단 ‹ 폴더 → 시트 목록 → 라이브러리 (push) | 아래에서 올라오는 시트 (55%) |
| medium | 시트 목록 + 에디터 | 상단 라이브러리 버튼 → overlay | 오른쪽 overlay |
| expanded | 라이브러리 + 시트 목록 + 에디터 | — | 오른쪽 overlay |
| large | expanded 와 같음 | — | 오른쪽에 붙음 (`pane.inspector`) |

> **웹 앱에서 써보고 바꾼 규칙 (2026-10-23, 검토 필요 · ADR-0007)** — 위 표대로면 840px 에서 에디터 글줄이 204px, 1200px 에서 인스펙터를 붙이면 212px 로 쓸 수 없을 만큼 좁다.
> 그래서 pane 은 **에디터가 600 이상 남을 때만 붙는다.** 우선순위는 에디터 → (열려 있으면) 인스펙터 → 시트 목록 → 라이브러리. 인스펙터는 에디터 580까지 허용 — 원고 옆에서 설정을 읽는 게 목적이라서. 못 붙는 pane 은 overlay(바깥 누르면 닫힘)로 연다.
> 결과(인스펙터 닫힘): 600–899 에디터만(목록 · 라이브러리 overlay) · 900–1139 목록 + 에디터 · 1140 이상 3단. 인스펙터를 열면 900 이상에서 붙고, 남는 폭만큼 목록 · 라이브러리가 접힌다.
> 확정되면 위 표와 `layout.json` 을 이 규칙으로 고친다.

- 에디터 본문 폭은 `editor.measure` 에서 멈춘다.
- 라이브러리: 작품 목록, 열린 작품만 펼쳐서 폴더(이름 · 시트 수). 열린 작품 줄을 다시 누르면 접히고 펼쳐진다(0.5.2). 폴더 목록 끝에 ＋ 새 폴더, 그 아래 **휴지통**(→ trash). 맨 아래 ＋ 새 작품 · 환경설정.
- 시트 목록 행: 제목 · 첫 줄 · 셋째 줄(회차 · 상태 · 예약일 · **올릴 본문** 글자수). 고친 시각은 행에 두지 않고 툴팁 · 인스펙터로. 어느 언어든 3줄을 넘지 않는다(긴 회차 표시는 말줄임). 갈라진 사본은 `branched`(git-branch, 주황), 손상은 `damaged`(file-warning, 빨강) — 모양으로도 가른다 (ADR-0002). 제목이 빈 시트는 "제목 없음".
- 시트 목록 머리의 ＋ 는 그 폴더 맨 아래(다음 회차 자리)에 빈 시트를 만들고 바로 연다. 시트 순서는 작가가 정한다(끌기 · ⌘⌥↑↓). 빈 시트의 에디터는 "첫 줄이 제목이 돼요" 자리표시.

## 에디터 상단 도구
왼쪽부터 (compact: ‹ 폴더 / medium: 라이브러리) … 명령 팔레트(데스크톱만) · 집중 모드 · 변경 기록 · 내보내기 · 인스펙터.

## 인스펙터 (오른쪽 패널)
수동으로 연다. 탭 셋:
- **참조** — 설정 폴더의 시트를 원고 옆에 띄운다 (PRODUCT.md "설정 참조").
- **정보** — 회차 상태 · 예약일 · 연재처(예약 · 발행일 때, 작은 입력 칸) 다음에 **올릴 본문** 묶음(공백 포함 · 제외 · 문피아 · 노벨피아)을 위에 모아 두고, 그 아래 원고 전체(공백 포함, 제목 · 기호 포함) · · ko 원고면 **원고지 매수**(200자), en 원고면 단어 수 · 문단 수 · 읽는 시간(ko 500자/분 · en 230단어/분) · 만든 날 · 고친 날.
- **개요** — 시트의 제목(#)과 문단 첫 줄 목록. 누르면 그 문단으로 간다.

## 집중 모드
- 라이브러리 · 시트 목록 · 인스펙터를 모두 닫고 에디터만. 상단에는 "집중 모드 끝내기"만 남는다.
- 커서가 있는 문단(환경설정에서 문장으로 바꿀 수 있음)만 그대로, 나머지는 `opacity.focusDim`.
- 하단 분량 표시는 남긴다 — 연재 작가에게 분량은 집중을 깨지 않는 정보다.

## 분량 표기 (하단)
- 항상 **공백 포함 · 공백 제외** 글자수 둘 다. (en 원고는 단어 수 — 원고 언어를 따른다, ADR-0005)
- 숫자는 **올릴 본문** 기준: core `platform_body`(제목 줄 · Markdown 기호 제외, 장면 구분 정규화)를 `count_for` 로 센다. 툴팁이 정의와 원고 전체 글자수를 알려 준다. 목표 진행도 같은 기준(PRODUCT 2026-10-24).
- 저장 상태 아이콘은 디스크(`savedLocal`) — 구름 아님. 툴팁: "원고는 이 Mac에만 저장돼요" + 마지막 백업 시각.
- 작품 설정에 목표가 있으면 하단 위에 진행 막대 + "목표 5,000 · 96%". 기준(공백 포함/제외/단어)은 작품 설정에서 고른다.
- 오른쪽 끝에 저장 · 동기화 상태("저장됨"). 문제가 생기면 이 자리에 경고가 뜬다.
- 일일 목표 · 연속 기록은 만들지 않는다.

## 상태
- `default` — 연재 폴더의 시트 편집 중.
- `readonly` — 다른 기기가 점유 중(ADR-0002). 경고 띠 + [점유하기], 본문 `opacity.readOnly`.
- `reference` — 인스펙터를 참조 탭으로 연 상태.
- `info` — 인스펙터를 정보 탭으로 연 상태.
- `focus` — 집중 모드.

## 플랫폼 관례 (프로토타입에서 흉내 내지 않음)
- 상단 바 · 뒤로 제스처 · 사이드바 토글 · 컨텍스트 메뉴(폴더 이름 바꾸기 · 삭제 · 시트 휴지통으로)는 각 OS 기본을 따른다.
- 데스크톱 메뉴 막대(파일 · 편집 · 보기 · 서식 · 시트 · 창 · 도움말)는 명령 팔레트와 같은 명령 목록으로 만든다.

## Mac (0.3.0)
실제 앱(swift/Sources/IthacaMac)이 하는 것. 위 공통 spec 과 다른 곳만 적는다.

**접기** — 위 "웹 앱에서 써보고 바꾼 규칙"을 그대로 쓴다(에디터 600 이상, 인스펙터는 580까지). compact 폭에서는 에디터 하나 + overlay. 붙지 못한 pane 은 scrim 위 overlay, 바깥을 누르면 닫힌다.

**라이브러리**
- 작품 순서 = 이 라이브러리에 더한 순서(가져오기 · 사본 복원은 맨 아래). 열린 작품만 펼친다.
- 작품 컨텍스트 메뉴: 작품 설정. 폴더 컨텍스트 메뉴: 폴더 정보(인스펙터 · 폴더 통계) · 이름 바꾸기(제자리 입력) · 삭제.
- 시트를 폴더 행에 끌어 놓으면 그 폴더 맨 아래로 옮긴다.
- 맨 아래 ＋ 새 작품 · 환경설정(톱니).

**시트 목록**
- 머리: 폴더 이름 / "시트 12개 · 29,822자"(en 은 단어) / 회차가 있으면 "비축 3화 · 다음 연재 10/26". 긴 문구는 툴팁. 머리를 누르면 인스펙터에 폴더 통계(→ episodes). 오른쪽 검색 · ＋.
- 행: 제목(빈 제목은 "제목 없음", `ink.tertiary`) · 첫 줄 · 셋째 줄 "3화 · 초고 · 4,812자 · 10월 24일 18:30". 손상 ⚠ `state.danger`(→ damaged-sheet), 갈라짐 ⚠ `state.warning`.
- 마우스를 올린 행 · 열린 행에 휴지통 버튼. 끌어서 순서 바꾸기(놓을 자리에 `accent.primary` 선), 마지막 행 아래에 놓으면 맨 끝.
- 컨텍스트 메뉴: 위로 · 아래로 · 다른 폴더로 옮기기 · (회차) 여기까지 발행으로 표시 · 외전·공지로 표시 · 변경 기록 · 내보내기… · 휴지통으로.
- ＋ 는 폴더 끝의 빈 시트가 이미 있으면 새로 만들지 않고 그것을 연다(빈 시트가 쌓이지 않게). 첫 폴더의 새 시트는 회차 "초고".

**에디터**
- 도구: (목록이 안 붙었을 때) 라이브러리 · … · 명령 팔레트 · 집중 모드 · 변경 기록 · 내보내기 · 인스펙터. 시트가 없으면 변경 기록 · 내보내기는 숨김.
- 본문 위 띠(위에서부터): 읽기 전용(→ library-error) · 열면서 찾은 문제(닫기) · 목차 손상 · 시트 손상(→ damaged-sheet).
- 자동 저장: 입력을 1.5초 멈추면. 한글 조합 중에는 기다린다. 시트 바꾸기 · 앱 비활성 · 종료 때 바로 저장. 실패하면 2 · 5 · 15 · 30 · 60초 간격으로 다시 시도.
- **저장 실패 시 글을 버리지 않는다.** 시트 바꾸기 · 지우기 · 종료가 막히고 경고창: 다시 시도 · 글 복사 · 파일로 내보내기… · (종료 중) 그래도 종료(한 번 더 확인) · 취소.
- 마지막으로 연 작품 · 폴더 · 시트, 작품별 마지막 시트, 시트별 커서 위치를 기억한다.
- 한글은 어절 단위 줄바꿈. undo 는 낱자가 아닌 단어 단위. 클립보드는 plain text 만(붙여넣기 · 복사 모두).

**하단**: ko 원고 "공백 포함 · 공백 제외", en 원고 "단어 · 공백 포함". 목표가 있으면 위에 진행 막대 + "목표 5,000 · 96%"(문피아 · 노벨피아 기준이면 붙여넣을 본문으로 셈). 오른쪽 "저장됨" / "저장 중" / "저장하지 못했어요 — 이유" + [다시 시도] (성공할 때까지 남는다).

**인스펙터**
- 참조: 작품의 아무 시트(열린 시트 제외)를 고른다. 기본은 둘째 폴더(설정)의 첫 시트, 고른 것은 기억.
- 정보: 시트 / 폴더 세그먼트. 시트 — 회차 상태 · 예약일 · 공백 포함 · 제외 · 원고지 매수(ko) 또는 단어(en) · 문단 · 읽는 시간 · 만든 날 · 고친 날 · (ko) 연재처 기준 문피아(글자 · 쪽) · 노벨피아. 폴더 — episodes spec.
- 개요: 제목(#)과 문단 첫 줄. 누르면 그 자리로 커서.

**토스트**: 도구 막대 아래 오른쪽(쓰는 줄을 가리지 않게). 6초, 마우스를 올리면 멈춤. 되돌리기가 없는 알림 · 오래 남는 알림(가져오기 결과 · 작품 삭제 · 형식 변환)엔 닫기.
