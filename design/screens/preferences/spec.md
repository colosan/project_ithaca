# preferences · 환경설정

앱 전체 설정. 작품 설정(project-settings)과 다르다 — 한국어 UI 에서 "설정"은 작품 설정집 폴더 이름이라 여기는 **환경설정**.

## 섹션 (사이드바는 네 묶음: 쓰기 · 데이터 · 연결 · 앱)
| 섹션 | 항목 |
|---|---|
| 일반 | 화면 언어(시스템 · 한국어 · English, 즉시 전환 ADR-0005) · 테마(시스템 · 라이트 · 다크) · 앱을 열 때(마지막 시트 · 라이브러리) · 휴지통 비우기(30일 뒤 · 직접) · 지우기 전에 확인 |
| 에디터 | **미리 보기**(열린 시트 앞부분을 고른 설정으로) · 글자 크기(작게 · 보통 · 크게 = `type.editor.small/body/large`) · Markdown 기호(보이기 · 흐리게 · 숨기기) · 첫 줄 들여쓰기 · 문단 사이 띄우기 · 집중 모드 범위(문장 · 문단) · 타자기 스크롤 · 맞춤법 · 둥근 따옴표 · 괄호 짝 닫기 |
| 동기화 | 상태 줄(맞춰짐 · 지금 동기화) · 중계 서버 주소 + 켜기 · iCloud Drive(Apple 기기만) · 기기 간 직접 연결 · 연결된 기기 목록 + 기기 추가 (ADR-0003) |
| 백업 | 자동 백업 · 주기(매시간 · 매일 · 매주) · 보관(10 · 30 · 전부) · 저장 위치(데스크톱은 바꾸기) · 최근 백업 목록 + 복원 · 지금 백업 |
| 단축키 | 일반 · 보기 · 서식 · 시트 묶음의 단축키 표. 보기만 하고 바꾸기는 다음 버전. 모바일은 "키보드 연결 시" 안내 |
| Claude 연동 (MCP) | **Mac · Windows 앱에서만.** 켜기 · 권한(읽기만 · 읽고 고치기) · 고치기 전에 묻기(고치기일 때) · 보여줄 작품 고르기 · 주소 · 토큰(복사 · 새로 발급) · Claude 앱 연결 설정 복사 · Claude 가 고친 기록 → history#claude. 모바일에서는 안내 문구만 |
| 정보 | 앱 이름 · 버전 · 업데이트 확인(데스크톱 직접 배포만 — 스토어 빌드는 스토어가 한다) · 라이선스 · 소스 코드 · 문제 알리기 · 오픈소스 라이선스 · 데이터 폴더(데스크톱) · 로컬 우선 안내 |

- 언어 선택지는 그 언어 자신의 이름으로 쓴다(한국어 · English) — UI 언어와 무관.
- 데스크톱 전용 여부는 **플랫폼**으로 정한다. 폭이 아니다(창을 좁혀도 Mac 은 Mac).
- 단축키 표기: Apple 은 수정키를 아이콘(⌘ ⇧ ⌥ → `command` · `keyShift` · `keyOption`)으로, Windows · Android 는 Ctrl · Shift · Alt 글자로.
- 백업 복원은 **덮어쓰지 않는다** — 라이브러리에 사본 작품으로 추가한다(원고가 조용히 사라지지 않는다, PRODUCT.md).
- 에디터 서체 선택은 `typography.families.editor` 가 `[미정]` 이라 아직 없다.

## size class
| class | 형태 |
|---|---|
| compact | 섹션 하나가 한 페이지. 상단 ‹ 환경설정 → 묶음으로 나뉜 섹션 목록 |
| medium 이상 | 왼쪽 섹션 목록 + 오른쪽 내용 (`pane.dialog` 폭에서 멈춤) |

- 세그먼트는 compact · medium · 글자 150% 이상에서 라벨 아래로 내려간다.

## 상태
- `general` · `editor` · `sync` · `backup` · `shortcuts` · `claude` · `about` — 열린 섹션.

## Mac (0.3.0)
환경설정 창은 **탭 다섯 개**: 일반 · 에디터 · 백업 · Claude · 정보. 동기화 · 단축키 탭은 동작할 때까지 숨긴다(ADR-0007 "동작하지 않는 항목은 보여주지 않는다"). 단축키는 메뉴 막대에 보인다.

| 탭 | 실제 항목 |
|---|---|
| 일반 | 화면 언어(시스템 · 한국어 · English) · 테마(세그먼트) · 지우기 전에 확인 · 휴지통(안내 "30일이 지나면 저절로 비워져요." — 바꾸기 없음). "앱을 열 때"는 없다 — 늘 마지막 시트 |
| 에디터 | 글자 크기 · Markdown 기호(보이기 · 흐리게 · 숨기기, 기본 흐리게) · 집중 모드 범위(문장 · 문단, 기본 문단) · 타자기 스크롤 · 맞춤법(시스템 사전, **원고 언어를 따라 ko 꺼짐 · en 켜짐**, 직접 바꾸면 그 값). 미리 보기 · 첫 줄 들여쓰기 · 문단 사이 · 둥근 따옴표 · 괄호 짝 닫기는 아직 없다 |
| 백업 | 라이브러리 폴더 경로 + Finder에서 보기 · 열면서 찾은 문제(있을 때) · 자동 백업 설명 "하루에 한 번 … 최근 7일과 4주치를 남기고, 직접 만든 백업은 지우지 않아요." + [지금 백업] · 저장 위치 Finder에서 보기 · 최근 백업 12개(시각 · 종류 자동/직접/형식 변환 전 · 크기 · 작품 수 · [사본으로 복원]) · 웹 버전에서 가져오기… |
| Claude | 아래 |
| 정보 | 버전 · 빌드 · core 버전 · format · 업데이트 자동 확인 + 지금 확인(Sparkle) · 라이선스 · 소스 코드 · 로컬 우선 안내("원고는 이 Mac에만 있어요." — 동기화 언급 없음) |

**백업 (공통 spec 과 다름 — 검토 필요)**: 주기 · 보관 개수 · 저장 위치 바꾸기 선택이 없다. 하루 한 번 자동, 최근 7일(날마다 가장 새 것) + 4주(주마다 가장 새 것, 월요일 기준), 이름 · 날짜는 Mac 의 현지 시각. 글이 든 시트가 하나도 없으면 자동 백업을 만들지 않는다(조용히). 직접 백업 · 형식 변환 전 백업은 지우지 않는다. 앱을 켤 때와 다른 앱으로 넘어갈 때 하루가 지났으면 백업한다.
**사본으로 복원**: 작품 제목 뒤에 "(백업 10월 24일)"을 붙여 라이브러리 맨 아래에 더한다. 기록(history)은 복사하지 않는다 — 백업에 남는다.

**Claude (ADR-0009 — 공통 spec 과 다름)**
- 켜기 "Claude가 원고를 읽게 하기" + "읽기만 해요. Claude는 원고를 고치거나 지울 수 없어요. 이 컴퓨터 안에서만 연결돼요."
- 켜면: "Claude에게 보여줄 작품" 체크 목록(기본 아무것도 안 켜짐, "체크한 작품만 Claude에게 보여요.") · "Claude 데스크톱 연결 설정" — 이 앱 번들의 `ithaca-mcp` 경로가 든 JSON + [복사] + 붙여넣는 곳 안내(Claude 데스크톱 → 설정 → 개발자 → 구성 편집) · 앱을 옮기면 다시 복사하라는 안내 · 번들에 서버가 없으면 경고.
- 연결 돕기(2026-10-24): JSON 위에 상태 줄 "Claude 데스크톱 설정에 추가했는지 확인하세요"(설정 파일에 `ithaca` 가 있으면 "…설정 파일에 들어 있어요") · [설정 파일에 추가](`~/Library/Application Support/Claude/` 가 있을 때만 — 기존 파일을 `claude_desktop_config.ithaca-backup-<시각>.json` 으로 복사한 뒤 다른 서버 · 키는 두고 `mcpServers.ithaca` 만 넣어 원자적으로 씀, JSON 이 깨져 있으면 손대지 않음) · [Claude 데스크톱 설정 폴더 열기].
- **권한 선택(읽고 고치기) · 고치기 전에 묻기 · 주소 · 토큰 · Claude가 고친 기록 링크는 없다.** stdio 라서 토큰이 필요 없고, 쓰기 도구가 아직 없다.
- 설정은 라이브러리의 `mcp.json` 에 저장되고 Claude 의 다음 요청부터 적용된다(Claude 재시작 필요 없음). 읽기 전용 라이브러리에서는 바꿀 수 없다.
