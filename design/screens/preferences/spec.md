# preferences · 환경설정

앱 전체 설정. 작품 설정(project-settings)과 다르다 — 한국어 UI 에서 "설정"은 작품 설정집 폴더 이름이라 여기는 **환경설정**.

## 섹션 (사이드바는 네 묶음: 쓰기 · 데이터 · 연결 · 앱)
| 섹션 | 항목 |
|---|---|
| 일반 | 화면 언어(시스템 · 한국어 · English, 즉시 전환 ADR-0005) · 테마(시스템 · 라이트 · 다크) · 앱을 열 때(마지막 시트 · 라이브러리) · 휴지통 비우기(30일 뒤 · 직접) · 지우기 전에 확인 |
| 에디터 | **미리 보기**(열린 시트 앞부분을 고른 설정으로) · 글자 크기(작게 · 보통 · 크게 = `type.editor.small/body/large`) · Markdown 기호(보이기 · 흐리게 · 숨기기) · 첫 줄 들여쓰기 · 문단 사이 띄우기 · 집중 모드 범위(문장 · 문단) · 타자기 스크롤 · 맞춤법 · 둥근 따옴표 · 괄호 짝 닫기 |
| 동기화 | 상태 줄(맞춰짐 · 지금 동기화) · 중계 서버 주소 + 켜기 · iCloud Drive(Apple 기기만) · 기기 간 직접 연결 · 연결된 기기 목록 + 기기 추가 (ADR-0003) |
| 백업 | 자동 백업 · 주기(매시간 · 매일 · 매주) · 보관(10 · 30 · 전부) · 저장 위치(데스크톱은 바꾸기) · 최근 백업 목록 + 복원 · 지금 백업 |
| 단축키 | 일반 · 보기 · 서식 · 시트 묶음의 단축키 표. 보기만 하고 바꾸기는 다음 버전. 모바일은 "키보드 연결 시" 안내 |
| Claude 연동 (MCP) | **Mac · Windows 앱에서만.** 켜기 · 권한(읽기만 · 읽고 고치기) · 고치기 전에 묻기(고치기일 때) · 보여줄 작품 고르기 · 주소 · 토큰(복사 · 새로 발급) · Claude 앱 연결 설정 복사 · Claude 가 고친 기록 → history#claude. 모바일에서는 안내 문구만 |
| 정보 | 앱 이름 · 버전 · 업데이트 확인(데스크톱 직접 배포만 — 스토어 빌드는 스토어가 한다) · 라이선스 · 소스 코드 · 문제 알리기 · 오픈소스 라이선스 · 데이터 폴더(데스크톱) · 로컬 우선 안내 |

- 언어 선택지는 그 언어 자신의 이름으로 쓴다(한국어 · English) — UI 언어와 무관.
- 데스크톱 전용 여부는 **플랫폼**으로 정한다. 폭이 아니다(창을 좁혀도 Mac 은 Mac).
- 단축키 표기: Apple 은 수정키를 아이콘(⌘ ⇧ ⌥ → `command` · `keyShift` · `keyOption`)으로, Windows · Android 는 Ctrl · Shift · Alt 글자로.
- 백업 복원은 **덮어쓰지 않는다** — 라이브러리에 사본 작품으로 추가한다(원고가 조용히 사라지지 않는다, PRODUCT.md).
- 에디터 서체 선택은 `typography.families.editor` 가 `[미정]` 이라 아직 없다.

## size class
| class | 형태 |
|---|---|
| compact | 섹션 하나가 한 페이지. 상단 ‹ 환경설정 → 묶음으로 나뉜 섹션 목록 |
| medium 이상 | 왼쪽 섹션 목록 + 오른쪽 내용 (`pane.dialog` 폭에서 멈춤) |

- 세그먼트는 compact · medium · 글자 150% 이상에서 라벨 아래로 내려간다.

## 상태
- `general` · `editor` · `sync` · `backup` · `shortcuts` · `claude` · `about` — 열린 섹션.
