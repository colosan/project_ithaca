# preferences · 환경설정

앱 전체 설정. 작품 설정(project-settings)과 다르다 — 한국어 UI 에서 "설정"은 작품 설정집 폴더 이름이라 여기는 **환경설정**.

## 섹션
| 섹션 | 항목 |
|---|---|
| 일반 | 화면 언어(시스템 · 한국어 · English, 즉시 전환 ADR-0005) · 테마(시스템 · 라이트 · 다크) |
| 동기화 | 중계 서버 주소 + 켜기 · iCloud Drive(Apple 기기만) · 기기 간 직접 연결 · 연결된 기기 목록 + 기기 추가 (ADR-0003) |
| Claude 연동 (MCP) | **Mac · Windows 앱에서만.** MCP 서버 켜기 · 주소 · 토큰(복사). 모바일에서는 안내 문구만 |

- 언어 선택지는 그 언어 자신의 이름으로 쓴다(한국어 · English) — UI 언어와 무관.
- 데스크톱 전용 여부는 **플랫폼**으로 정한다. 폭이 아니다(창을 좁혀도 Mac 은 Mac).

## size class
| class | 형태 |
|---|---|
| compact | 섹션 하나가 한 페이지. 상단 ‹ 환경설정 |
| medium 이상 | 왼쪽 섹션 목록 + 오른쪽 내용 (`pane.dialog` 폭에서 멈춤) |

## 상태
- `general` · `sync` · `claude` — 열린 섹션.
