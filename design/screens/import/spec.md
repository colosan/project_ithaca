# import · 가져오기 (계획 — Mac 0.3.0 에 구현됨)

다른 곳에 있던 원고를 **새 작품으로** 들인다. 지금 있는 작품은 절대 덮어쓰지 않는다. 프로토타입이 없어 planned 로 둔다.

## 들어오는 길
- 파일 메뉴 → 웹 버전에서 가져오기… · 텍스트 폴더 가져오기…
- 첫 실행 화면(new-project `first-run`)의 "쓰던 원고가 있나요?" 칸 — 두 버튼
- 환경설정 → 백업 → 웹 버전에서 가져오기…
- 명령 팔레트 "웹 버전에서 가져오기"

## 웹 버전 백업 (JSON, ADR-0007/0008)
- 웹 버전 환경설정 → 백업 → 지금 백업으로 받은 `ithaca-backup-날짜.json` 을 고른다.
- 작품 · 폴더 · 시트가 순서 그대로 새 작품(새 id)으로. 지운 작품 · 폴더 · 휴지통의 시트는 가져오지 않는다. 제목은 그대로(꼬리표 없음). 시트의 만든 날 · 고친 날은 유지.
- 각 작품의 **첫 폴더** 시트는 1..n 화 · 초고가 된다. 다른 폴더는 회차 정보 없음.

## 텍스트 폴더 (한글 · 메모장 · Scrivener 내보내기)
- 폴더 하나 → **작품 하나**. 작품 이름 = 폴더 이름. 원고 언어는 한글 비율로 정한다(글자의 20% 이상이 한글이면 ko).
- `.txt` `.md` `.markdown`(대소문자 무관) 하나 = 시트 하나. 폴더 바로 아래 파일 → 첫 폴더 "연재"(en "Episodes"). 하위 폴더 → 폴더 하나, 더 깊은 파일은 그 하위 폴더로 모은다. 가져올 게 없는 하위 폴더는 빠진다.
- **순서**: 이름의 자연 정렬 — 숫자는 값으로("2화" < "10화", "제2화" < "제10화", "02" = "2"), 숫자가 글자보다 먼저, 글자는 대소문자 무시. 폴더도 같은 규칙.
- **인코딩**: BOM(UTF-8 · UTF-16) → 올바른 UTF-8 → 아니면 CP949(EUC-KR). 줄바꿈은 `\n` 으로.
- **제목**: 첫 줄(빈 줄 제외)을 그대로 제목으로 둔다. 첫 줄이 60자를 넘거나(문단) 파일이 비었을 때만 맨 앞에 `# 파일 이름` 을 넣는다.
- 첫 폴더의 시트는 1..n 화 · 초고. 만든 날 = 고친 날 = 파일의 수정 시각.
- 조용히 건너뜀: 숨김 항목(`.DS_Store`, `.git/`) · 심볼릭 링크. **알리고 건너뜀**: 5 MB 넘는 파일 · 읽지 못한 파일 · 다른 확장자("표지.jpg (not .txt or .md)").

## 진행 · 결과
- 가져오는 동안 창을 막는 진행 표시("텍스트 폴더를 가져오는 중이에요…") — 두 번 누르지 못한다.
- 전부 아니면 전무: 실패하면 반쯤 들어온 작품이 남지 않는다(다시 해도 겹치지 않음).
- 끝나면 새 작품을 열고, 닫을 때까지 남는 토스트 "텍스트 폴더에서 시트 12개를 가져왔어요 — ‘작품’ 파일 1개는 건너뛰었어요."
- 건너뛴 파일이 있으면 "건너뛴 파일" 창(경로 (이유) 한 줄씩, 글자 선택 가능)을 띄운다.
- 가져온 작품은 라이브러리 맨 아래에 붙는다(작품 순서 = 이 라이브러리에 더한 순서).
- 읽기 전용 라이브러리에서는 텍스트 폴더 가져오기가 동작하지 않는다.

## 상태 (그릴 때)
- `picking` — 첫 실행 화면의 가져오기 칸.
- `busy` — 진행 표시.
- `skipped` — 건너뛴 파일 목록.

## 미정
- 다른 글쓰기 앱의 프로젝트 파일을 직접 읽기(PRODUCT.md [미정] 3, 자료조사 P2).
- 텍스트 폴더에서 작품 이름 · 언어를 가져오기 전에 고치는 단계 — 지금은 묻지 않고 나중에 작품 설정에서 바꾼다.
