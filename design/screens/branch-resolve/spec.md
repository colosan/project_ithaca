# branch-resolve · 갈라진 사본 정리

## 언제
오프라인에서 두 기기가 같은 시트를 고쳐서 갈라졌을 때(ADR-0002). 진 쪽은 갈라진 사본으로 보존되고, **다음에 그 시트를 열면 이 화면이 먼저** 뜬다. "나중에"를 누르면 시트는 읽기 전용으로 남는다.

## 원칙
- 하나를 고르는 화면이 아니다. **양쪽 다 편집 가능**하고, 사본 쪽 문단을 [← 가져오기]로 본문에 옮긴다.
- 문단 단위로 줄을 맞추고, 바뀐 문단 안에서는 글자 단위로 강조한다(Rust core `ithaca-diff`).
- 같은 문단은 흐리게(`ink.tertiary`), 다른 문단은 `state.warning` 테두리.
- [정리 완료] → `Merge { parents: [본문, 사본] }` 블록 기록, 사본은 이력으로만 남는다.

## size class
| class | 레이아웃 |
|---|---|
| compact | 바뀐 문단마다 카드 한 장. 본문/사본 탭 + 좌우 swipe로 다음 문단, 아래 점으로 위치 |
| medium 이상 | 좌(본문) · 우(사본) 두 열, 문단 행 정렬 |

## 상태
- `default` — 정리 시작 전 (0/2 정리됨).
