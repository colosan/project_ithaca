# library-error · 라이브러리를 열 수 없을 때 · 읽기 전용 (계획 — Mac 0.3.0 에 구현됨)

라이브러리 폴더를 못 열었거나, 열었지만 쓰면 안 될 때. 원칙은 하나 — **다른 곳에 써 버리지 않는다.** 메모리 속 임시 저장소로 대신 열지 않는다(거기 쓴 글은 사라지므로).
프로토타입이 없어 planned 로 둔다.

## 열지 못함 (`open-failed`)
- 창 전체가 이 화면이다(환경설정 창도 같은 화면). 메뉴 명령은 아무것도 하지 않는다.
- ⚠(`state.danger`) "라이브러리를 열지 못했어요" · 오류 문구(선택 가능) · 라이브러리 경로 · "다른 곳에 써 버리지 않도록 편집은 막아 두었어요. 폴더를 확인한 뒤 다시 시도해 주세요."
- [Finder에서 보기] (폴더가 없으면 상위 폴더) · [다시 시도](주) — 열리면 바로 앱으로.
- 폭은 `pane.dialog` 에서 멈추고 가운데.

## 읽기 전용으로 열림 (`read-only`)
원인은 넷 — 에디터 위 띠(`lease` 아이콘, `state.warning`)의 문구가 원인을 말한다.
| 원인 | 띠 문구 |
|---|---|
| **다른 Ithaca 가 쓰고 있음**(라이브러리 `.lock`) — 앱을 두 번 띄움, 다른 빌드 | "다른 Ithaca가 이 라이브러리를 쓰고 있어요 — 읽기 전용이에요." |
| 더 새 형식(새 버전 앱으로 쓰다가 옛 버전을 엶) | "이 라이브러리는 더 새 버전의 Ithaca로 만들어져서 읽기만 할 수 있어요. 앱을 업데이트해 주세요." |
| `library.json` 이 없거나 읽히지 않음 · 마이그레이션 실패(변환 전 백업으로 되돌림) | 지금은 "더 새 버전" 문구가 그대로 나온다 — 원인별 문구가 필요하다([미정]). 이유는 환경설정 → 백업 "열면서 찾은 문제"에 |

- 읽기 전용이면: 본문 `opacity.readOnly` · 새 시트 ＋ 숨김 · 회차 · 텍스트 폴더 가져오기 · 사본으로 복원 · 지금 백업 · Claude 설정 끔. 자동 백업도 하지 않는다. (웹 버전 가져오기는 버튼이 남아 있고 core 의 읽기 전용 오류로 끝난다 — 고칠 것)
- 첫 실행 화면을 띄우지 않는다(빈 라이브러리처럼 보여도).
- 다른 Ithaca 가 쓰는 중인 경우, 열린 순간의 모습이다 — 그쪽에서 쓴 새 글은 보이지 않는다. 그쪽을 끄고 이 앱을 다시 연다.
- 저장하려 하면 하단 상태가 "저장하지 못했어요 — (원인 문구)"로 남는다.

## 열면서 찾은 문제 (`problems`)
- 읽지 못한 작품은 건너뛰고(디스크엔 그대로) 나머지로 연다. 에디터 위 닫을 수 있는 띠 "라이브러리를 열면서 문제를 N개 찾았어요. 자세한 내용은 환경설정 → 백업에 있어요."
- 문제 줄: 한국어 화면에서는 알려진 core 문구를 `problem.*` 문자열로 바꿔 보여 주고(모르는 문구는 `problem.other`), core 원문(영어)은 툴팁에만. 오류 토스트도 `error.*`(core 오류 종류별) — en 화면만 원문을 괄호로 덧붙인다(ADR-0005).

## 상태 (그릴 때)
- `open-failed` · `read-only` · `problems`
