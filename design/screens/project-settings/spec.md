# project-settings · 작품 설정

## 무엇
작품 하나의 설정. 라이브러리에서 작품 이름의 컨텍스트 메뉴 → 작품 설정.

| 항목 | 내용 |
|---|---|
| 제목 | 작품 이름 |
| 원고 언어 | 한국어 / 영어 — 분량 단위를 정한다(ADR-0005) |
| 시트 목표 분량 | 숫자 + 기준(공백 포함 · 공백 제외 · 단어). 없음 가능. 정하면 에디터 하단에 진행 막대 |
| 폴더 | 이름 바꾸기 · 삭제 · 순서(≡ 끌기) · ＋ 새 폴더. 기본은 연재 · 설정 · 자료 |

- 일일 목표 · 연속 기록 없음 (PRODUCT.md).
- 폴더 템플릿(폴더별 기능)은 나중 — 자리만 비워 둔다.
- 폴더 삭제는 확인을 받는다(시트가 있으면 개수를 보여줌) — 다이얼로그는 플랫폼 관례.

## size class
| class | 형태 |
|---|---|
| compact | 전체 화면 페이지. 상단 ‹ 뒤로 · 제목 · 완료 |
| medium 이상 | 가운데 다이얼로그 (`pane.dialog`), 뒤는 scrim |

- `default`
