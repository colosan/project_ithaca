# project-settings · 작품 설정

## 무엇
작품 하나의 설정. 라이브러리에서 작품 이름의 컨텍스트 메뉴 → 작품 설정.

| 항목 | 내용 |
|---|---|
| 제목 | 작품 이름 |
| 원고 언어 | 없음 — 한국어 전용(ADR-0011). 예전에 만든 영어 작품은 그대로 단어 수로 센다 |
| 시트 목표 분량 | 숫자 + 기준(공백 포함 · 공백 제외 · 단어). 없음 가능. 정하면 에디터 하단에 진행 막대 |
| 폴더 | 이름 바꾸기 · 삭제 · 순서(≡ 끌기) · ＋ 새 폴더. 기본은 연재 · 설정 · 자료 |

- 일일 목표 · 연속 기록 없음 (PRODUCT.md).
- 폴더 템플릿(폴더별 기능)은 나중 — 자리만 비워 둔다.
- 폴더 삭제는 확인을 받는다(시트가 있으면 개수를 보여줌) — 다이얼로그는 플랫폼 관례.

## size class
| class | 형태 |
|---|---|
| compact | 전체 화면 페이지. 상단 ‹ 뒤로 · 제목 · 완료 |
| medium 이상 | 가운데 다이얼로그 (`pane.dialog`), 뒤는 scrim |

## 상태
- `default`

## Mac (0.3.0)
- 라이브러리의 작품 컨텍스트 메뉴 · 시트 메뉴 · 팔레트에서 연다. 가운데 시트 창.
- 원고 언어 아래 안내(분량 단위가 바뀜). 목표 기준: 공백 포함 · 공백 제외 · 단어 + (ko) **문피아 · 노벨피아**(붙여넣을 본문으로 셈, ADR-0009 §8). 이미 저장된 기준은 언어를 바꿔도 목록에 남는다.
- 폴더: 이름 바꾸기(Enter 또는 창을 닫을 때) · 시트 수 · 삭제(확인, 시트는 휴지통으로 → trash) · ＋ 새 폴더. **순서 바꾸기(끌기)는 아직 없다.**
- 왼쪽 아래 [작품 삭제](`state.danger`): 확인 → 30일 보관, 닫을 때까지 남는 되돌리기 토스트. [취소] · [완료].

## Mac (0.5.2) — 사용자 피드백으로 줄임
- 작품 설정은 **제목 · 시트 목표 분량 · 작품 지우기**만 둔다.
  - 폴더는 사이드바에서 관리한다(오른쪽 클릭 → 이름 바꾸기 · 지우기, ＋ 새 폴더). 같은 일을 두 곳에서 하지 않는다.
  - 원고 언어는 작품마다 고르지 않는다. 새 작품은 환경설정의 화면 언어를 따른다. 이미 만든 작품의 언어는 그대로다.
- 목표 분량은 체크박스 대신 팝업 하나다: **없음** · 공백 포함 · 공백 제외 · 단어 · (ko) 문피아 · 노벨피아. 기준을 고르면 옆에 숫자 칸이 나온다.
  - 체크박스는 라벨 없이 작았고, 꺼져 있을 때 숫자 칸이 흐리게 잠겨 있어서 "켤 수 없다"고 보였다.
