# trash · 휴지통 (계획)

지운 시트 · 폴더를 모아두는 곳. 라이브러리 폴더 목록 아래에서 연다.

## 그릴 것
- 지운 항목 목록: 제목 · 원래 폴더 · 지운 날 · 남은 날(환경설정 "30일 뒤"일 때).
- 항목마다 **되살리기**(원래 폴더로, 폴더가 없으면 새로 만든다) · **영구 삭제**(확인 필요).
- 상단 "휴지통 비우기"(확인 필요).
- 비었을 때: 빈 상태 문구.

## 원칙
- 지우기는 hash chain 에 `Delete` 기록을 쌓는다. 되살리기도 새 기록 — 기록 자체는 지우지 않는다(ADR-0002 와 같은 결).
- 영구 삭제만 블록 파일을 지운다. 다른 기기에도 전해진다.

## 미정
- 영구 삭제가 다른 기기 백업에 남은 사본까지 지우는가.
