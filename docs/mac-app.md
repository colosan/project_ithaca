# Ithaca Mac 앱 — 쓰는 사람을 위한 안내

## 설치

- **이 Mac에서 직접 빌드한 경우**
  - `tools/mac/build.sh`로 빌드하고 `tools/mac/install.sh`로 설치한다. `/Applications/Ithaca.app`에 들어간다.
  - 직접 빌드한 앱이라 Gatekeeper 경고가 뜨지 않는다.
- **GitHub Release에서 받은 경우** — https://github.com/colosan/project_ithaca/releases/latest 의 `Ithaca-<버전>.zip`
  1. zip을 풀어 `Ithaca.app`을 `/Applications`로 옮긴다.
  2. 처음 한 번 열면 경고가 뜬다. 시스템 설정 → 개인정보 보호 및 보안 → **그래도 열기**를 누른다.
  - 자세한 이유는 `tools/mac/README.md`에 있다.

## 원고는 어디에 저장되나

- **라이브러리 폴더**: `~/Library/Application Support/Ithaca/Library/`
  - 환경설정 → 백업의 "Finder에서 보기"로 바로 열 수 있다.
  - 원고는 작품별 폴더 안에 **바뀌지 않는 작은 파일**(변경 기록 블록)로 쌓인다. 파일을 직접 고치거나 지우지 않는다. 형식은 `core/FORMAT.md`에 있다.
  - 지운 시트는 휴지통에서 30일간 되살릴 수 있다. 지운 작품도 30일간 보관한다.
- **자동 백업**: `~/Library/Application Support/Ithaca/Backups/`
  - 앱이 하루에 한 번 백업한다. 최근 7일치와 4주치를 보관한다.
  - "지금 백업"으로 만든 수동 백업과, 업데이트 직전 형식 변환 백업은 지우지 않는다.
  - 복원하면 백업의 작품이 **사본으로 추가**된다. 지금 있는 원고는 덮어쓰지 않는다.
  - 더 안전하게 하려면 이 `Ithaca` 폴더째로 Time Machine이나 외장 디스크에 백업해 둔다.

## 업데이트

- 앱이 하루에 한 번 GitHub Release를 확인한다. 메뉴의 "업데이트 확인…"으로 바로 확인할 수도 있다.
- 업데이트는 서명을 확인한 뒤에만 설치된다(Sparkle). 원고는 앱 밖의 라이브러리 폴더에 있어서 업데이트해도 그대로 남는다.
- **새 버전이 데이터 형식을 바꾸는 경우**
  1. 처음 열 때 라이브러리 전체를 `Backups/pre-migration-…`에 복사한다.
  2. 그다음 형식을 변환한다.
  - 옛 버전 앱으로 새 형식 라이브러리를 열면 **읽기 전용**으로 열린다. 아무것도 쓰지 않는다.

## 웹 버전에서 옮겨오기

1. 웹 버전(`pnpm app` → http://localhost:9152)에서 환경설정 → 백업 → **지금 백업**을 누른다. `다운로드`에 `ithaca-backup-날짜.json`이 저장된다.
2. Mac 앱의 파일 메뉴 → **웹 버전에서 가져오기…**를 고른다. 처음 실행할 때의 화면에서도 할 수 있다.
3. 받은 JSON을 고른다. 작품 · 폴더 · 시트가 순서 그대로 **새 작품으로** 들어온다. 휴지통의 시트는 가져오지 않는다.

## 텍스트 폴더 가져오기

한글 · 메모장 · Scrivener에서 `.txt` · `.md`로 내보낸 원고 폴더를 **새 작품 하나**로 들인다.

1. 파일 메뉴 → **텍스트 폴더 가져오기…** (처음 실행할 때의 화면에서도 할 수 있다)
2. 폴더를 고른다. 폴더 이름이 작품 이름이 된다.

- 폴더 바로 아래 파일은 "연재" 폴더로, 하위 폴더는 같은 이름의 폴더로 들어간다.
- 순서는 이름순인데 숫자는 값으로 센다: `2화` → `10화` 순. 앞에 `0`을 붙일 필요가 없다.
- 한글 파일이 깨지지 않게 인코딩을 알아서 고른다(UTF-8, 아니면 CP949/EUC-KR).
- 시트 제목은 파일의 첫 줄이다. 첫 줄이 너무 길면(60자 넘음) 파일 이름을 제목으로 붙인다.
- 연재 폴더의 시트는 1화부터 차례로 번호가 붙고 상태는 "초고"다.
- 그림 · 5 MB 넘는 파일처럼 못 가져온 파일은 끝나고 목록으로 보여준다. 나머지는 모두 들어온다.
- 지금 있는 작품은 건드리지 않는다. 마음에 안 들면 새 작품만 지우면 된다.

## 회차 · 예약 · 비축

작품의 **첫 폴더(연재)** 시트가 회차다.

- **번호 매기기**: 시트를 원하는 순서로 놓은 뒤 시트 메뉴 → **회차 번호 다시 매기기**. 폴더의 시트가 1화부터 차례로 번호를 받는다.
- **프롤로그 · 외전 · 공지**: 시트를 오른쪽 클릭 → **외전·공지로 표시 (번호 제외)**. 번호를 건너뛰고 비축분에도 세지 않는다.
- **상태 · 예약**: 인스펙터(⌥⌘I) → 정보 → 회차 상태(초고 · 퇴고 · 예약 · 발행). "예약"을 고르면 발행 예약일을 정할 수 있다(처음엔 내일 18:00).
- **올린 회차 표시**: 마지막으로 올린 시트를 오른쪽 클릭 → **여기까지 발행으로 표시**. 그 앞의 회차도 모두 "발행"이 된다.
- **비축분 · 다음 연재일**: 시트 목록 머리에 "비축 3화 · 다음 연재 10/26"이 보인다. 비축 = 아직 발행 안 한 회차 수.
- **폴더 통계**: 시트 목록 머리(폴더 이름)를 누르면 인스펙터에 합계 분량 · 회차 평균 · 문피아 · 노벨피아 기준 글자수 · 상태별 회차 수가 나온다.
- 작품 설정의 시트 목표 기준을 **문피아 · 노벨피아**로 고르면 하단 진행률이 그 플랫폼 본문 칸에 붙여 넣을 글(제목 줄 제외)로 계산된다.

## Claude 연동 (읽기 전용)

Claude 데스크톱 앱이 이 Mac의 원고를 **읽게** 한다. Claude는 원고를 고치거나 지울 수 없다. 인터넷 서버를 거치지 않고 이 Mac 안에서만 연결된다.

1. Ithaca → 환경설정(⌘,) → **Claude** → "Claude가 원고를 읽게 하기"를 켠다.
2. **Claude에게 보여줄 작품**을 체크한다. 체크한 작품만 보인다(처음엔 아무것도 체크되어 있지 않다).
3. "Claude 데스크톱 연결 설정"의 **복사**를 누른다.
4. Claude 데스크톱 → 설정 → 개발자 → **구성 편집(Edit Config)** 으로 열리는 `claude_desktop_config.json`에 붙여넣는다.
   - 이미 다른 서버가 있으면 `"mcpServers"` 안에 `"ithaca"` 항목만 더한다.
5. Claude 데스크톱을 **완전히 종료하고 다시 연다.** 대화 창에서 "내 작품 목록 보여줘", "설정집에서 주인공 설정 찾아줘"처럼 묻는다.

- 작품 체크를 바꾸거나 연동을 끄는 것은 Claude를 다시 열지 않아도 다음 질문부터 적용된다.
- Ithaca.app을 다른 폴더로 옮겼으면 3–5를 다시 한다(경로가 바뀐다).
- Claude가 "Ithaca에서 Claude 연동을 켜라"는 오류를 전하면 1단계가 꺼져 있거나, 물은 작품이 2단계에서 체크되지 않은 것이다.

## 손상된 시트 되살리기

디스크 오류나 손으로 고친 파일 때문에 시트의 기록 일부가 깨질 수 있다. Ithaca는 깨진 시트를 비우거나 덮어쓰지 않는다.

- 목록에 빨간 ⚠가 붙고, 열면 **마지막으로 온전한 내용**을 읽기 전용으로 보여준다.
- **백업에서 되살리기**를 누른다. 자동 · 수동 백업에서 그 시트의 온전한 기록을 찾아 되돌린다.
- 맞는 백업이 없으면 **마지막 온전한 내용으로 계속 쓰기**를 누른다. 보이는 글에서 이어 쓸 수 있다.
- 무엇을 하든 **글 복사**로 지금 보이는 글을 먼저 받아 둘 수 있다.
- 깨진 파일은 지우지 않고 작품 폴더 안 `damaged/`에 옮겨 둔다.
- "목차 기록이 손상됐다"는 띠가 뜨면 그 작품에서 시트 추가 · 이동이 저장되지 않는다. 환경설정 → 백업에서 최근 백업을 **사본으로 복원**한다.

## 다른 Ithaca가 열려 있을 때 (읽기 전용)

라이브러리는 한 번에 Ithaca 하나만 쓴다. 이미 열린 Ithaca가 있는데 또 열면(직접 빌드한 앱과 받은 앱을 같이 연 경우 등):

- 나중에 연 쪽은 "다른 Ithaca가 이 라이브러리를 쓰고 있어요 — 읽기 전용이에요." 띠와 함께 **읽기 전용**으로 열린다. 아무것도 쓰지 않는다.
- 연 순간의 내용만 보인다. 다른 쪽에서 쓴 새 글은 안 보인다.
- 쓰려면 **두 Ithaca를 모두 종료하고 하나만 다시 연다.**
- 라이브러리를 아예 열지 못하면 오류 화면이 뜬다. 폴더를 확인하고 **다시 시도**를 누른다. 이때도 다른 곳에 대신 쓰지 않는다.

## 자주 쓰는 단축키

| | |
|---|---|
| ⌘N / ⌘⇧N | 새 시트 / 새 작품 |
| ⌘K | 명령 팔레트(시트 · 문장 · 폴더 · 명령 찾기) |
| ⌘1 / ⌘2 / ⌘3 | 라이브러리 보이기 / 목록 보이기 / 에디터만 |
| ⌘F / ⌘⇧F | 시트 안에서 찾기 / 전체 검색 |
| ⌥⌘↑ / ⌥⌘↓ | 시트 순서 위로 / 아래로 |
| ⌘⌫ | 시트를 휴지통으로 (되돌리기 가능) |
| ⌘⇧D | 집중 모드 |
| ⌥⌘I | 인스펙터(참조 · 정보 · 개요) |
| ⌘⇧H | 변경 기록 |
| ⌘⇧E | 내보내기(연재처 붙여넣기용 · 파일) |
| ⌘S | 지금 저장(저장은 원래 자동이에요) |
| ⌘[ / ⌘] | 이전 시트 / 다음 시트 |
| ⌘G / ⌘⇧G | 다음 찾기 / 이전 찾기 |
| ⌘+ / ⌘- / ⌘0 | 글자 크게 / 작게 / 기본 |

### 서식 (Markdown 기호로 들어가요)

| | |
|---|---|
| ⌘B / ⌘I / ⌘⇧X | 굵게 `**` / 기울임 `*` / 취소선 `~~` — 다시 누르면 풀려요 |
| ⌥⌘1 · 2 · 3 / ⌥⌘0 | 제목 1 · 2 · 3 / 본문 |
| ⌥⌘' | 인용 `>` |
| ⌘⇧↩ | 장면 전환(`* * *`) 넣기 |
| ⌘/ | 특수문자 메뉴 — 1–9 · 0으로 바로 넣기 |

### 특수문자 (⌘/)

`…` `「」` `『』` `“”` `‘’` `―` `·` `※` `♡` `★`가 1–9 · 0번이고, 그 아래에 `《》` `〈〉` `【】` `♥` `☆` `♪` `～` `→` `×` `○` `●` `◆` `■` `▶`이 있어요.
- 괄호 · 따옴표는 글을 선택하고 고르면 그 글을 감싸요. 선택이 없으면 커서가 괄호 안에 들어가요.
- 서식 메뉴 → 특수문자에서도 고를 수 있어요.
