# ADR-0007 · 디자인 동결 전에 실제로 쓰는 웹 앱을 둔다

- 상태: 확정 (2026-10-23)
- 관련: [0006](0006-design-first.md) (보완), [0004](0004-ui-shells.md), [0005](0005-i18n.md)

## 맥락

ADR-0006에 따라 디자인을 먼저 확정하고 있다. 그런데 프로토타입은 고정 샘플 원고로 그린 그림이라서 **실제로 글을 써봐야 드러나는 문제**를 잡지 못한다. 예를 들면 이런 것들이다.
- 회차를 몇 개 쓴 뒤의 목록 정렬
- 긴 원고에서의 스크롤
- 지우기와 되살리기의 흐름
- 붙여넣기 규칙

1차 사용자(만든 사람 자신)가 디자인을 확정하기 전에 실제 원고로 매일 써볼 수 있어야 한다.

## 결정

1. **`app-web/`에 실제로 동작하는 웹 앱을 둔다** (`pnpm app`, http://localhost:9152).
   - 토큰, 문구, 아이콘, kit 컨트롤은 workbench와 **같은 생성물**을 쓴다(`@ithaca/kit`). 그래서 디자인을 바꾸면 웹 앱에도 그대로 반영된다.
   - 문구는 `design/strings`에만 둔다. 웹 앱이 필요로 하는 키도 거기에 더한다. 이 키들은 네이티브도 나중에 그대로 쓴다.
2. **범위는 "로컬 메모장 + 작품 구조"다.**
   - 작품 → 폴더 → 시트, 휴지통, 검색, 내보내기, 작품 설정, 분량과 목표, 집중 모드, 인스펙터.
   - 저장은 브라우저 localStorage에 한다. 백업은 JSON 파일로 받고 복원한다.
   - 탭 두 개에서 같은 시트를 쓰면, 마지막으로 쓴 탭이 그 시트를 점유한다(BroadcastChannel). ADR-0002의 점유 규칙을 브라우저 안에서 작게 적용한 것이다.
   - 백업 복원은 덮어쓰지 않는다. 백업의 작품을 사본으로 더한다.
   - 저장된 데이터를 읽지 못하면 그 데이터를 따로 보관한다. 덮어쓰지 않는다.
3. **하지 않는 것**
   - 기기 간 동기화, 기기 간 점유(lease), hash chain 기록, MCP, 분기 해소. 이것들은 Rust core(ADR-0001~0003)의 몫이다.
   - 웹 앱에서 흉내 내지 않는다. 환경설정에서도 동작하지 않는 항목은 보여주지 않는다.
4. **정본은 여전히 `design/`이다.** 웹 앱을 쓰다가 발견한 것은 spec, 프로토타입, PRODUCT.md에 되돌려 적는다.
5. **`core/`, `swift/`, `kotlin/`은 계속 동결한다**(ADR-0006).
6. 웹 앱의 데이터 모양(`app-web/src/store.ts`)은 core 모델(`ithaca-model`)을 설계할 때 참고 자료로 쓴다. 다만 구속력은 없다.

## 결과

- 의존성은 추가하지 않는다. Vite, React, lucide-react는 이미 쓰고 있다.
- 웹 앱 데이터는 브라우저 하나에만 있다. 그래서 앱 안에서 백업 파일을 자주 받아 두라고 안내한다.
- 나중에 에디터를 textarea에서 서식 표시가 되는 에디터(예: CodeMirror 6, MIT)로 바꾸면 새 의존성이 생긴다. 그때 라이선스를 확인하고 이 ADR을 갱신한다.
