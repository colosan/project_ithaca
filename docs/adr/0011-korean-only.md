# ADR-0011 · 한국어 전용 · "원고"

- 상태: 확정 (2026-10-29). 소유자가 정했다 — "점점 한국어 전용 앱으로 가고 있으니 아예 한국어 특화로".
- 바꾸는 것: [0005](0005-i18n.md) 의 ko / en 두 언어 · 앱 안 언어 전환 · 원고 언어 선택.

## 맥락
- 기능이 한국어 연재 쪽으로 쏠렸다: 조사(은/는) · 회차 번호 · 연재처 글자수 기준 · 어절 줄바꿈 · 문피아 · 노벨피아 분량.
- 영어 문구 약 740개를 함께 고치는 비용이 매 기능마다 붙는다. 영어 화면을 쓰는 사람이 없다.
- 제품 인상: 범용 글쓰기 앱과 같은 용어("시트")를 쓰면 그 앱의 아류로 보인다.

## 결정
1. **화면은 한국어 하나.** `design/strings/ko.json` 만 정본이다. 앱 안 언어 선택을 없앤다.
   - 문구를 키로 두고 생성하는 구조(`L10n`)는 그대로 둔다 — 오타 난 키가 컴파일 에러가 되는 장점 때문.
2. **새 작품은 한국어 원고.** 새 작품 창에서 원고 언어를 고르지 않는다.
   - core 의 형식(작품의 `language`)은 그대로다. 예전에 만든 영어 작품도 그대로 열리고 단어 수로 센다.
   - MCP tool 설명은 영어로 둔다(Claude 가 읽는 것).
3. **"시트" 대신 "원고".** 화면 문구에서 글 한 편은 "원고"다(새 원고 · 원고 목록 · 이 원고). 회차 번호는 지금처럼 "12화"로 따로 보인다.
   - 코드 · spec 의 `sheet` 는 내부 이름으로 남는다.
4. 디자인 문서는 다른 앱을 기준으로 적지 않는다. 우리 원칙으로만 적는다.

## 결과
- `pnpm design:check` 의 locale 검사는 ko 하나만 본다. 스냅숏 매트릭스 · Mac 스냅숏에서 en 장면을 뺐다.
- 웹 임시 버전(ADR-0007)도 언어 선택에서 English 를 뺐다.
