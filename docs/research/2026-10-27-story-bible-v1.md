# 설정 시트 · 에디터 연계 기획 v1 (초안, 검토 전)

> 2026-10-27. 소유자 방향: 통계·대시보드 말고 **에디터 강화**. 설정과 연계, 인물·장소는 형식 있는 특수 시트(자유 md 보다 실제로 도움 되는 템플릿), 자동완성과 연계하되 "서"만 쳐도 "서윤"이 뜨는 식은 집필 방해. 맞춤법 · 특수문자 · 들여쓰기 같은 편의도 필요.
> 이 문서는 v1 이다. 검토(찬성 · 반박) 뒤 v2 로 다듬는다.

## 지금 앱 (0.5.9)
- 작품 → 폴더(기본 연재 · 설정 · 자료) → 시트. 시트는 모두 자유 Markdown.
- 인스펙터 참조 탭: 설정 폴더의 시트를 손으로 골라 옆에 띄워 봄.
- Claude(MCP) 읽기 전용으로 원고 · 설정을 읽음.
- 특수문자 메뉴 ⌘/ (1–9 · 0 바로 넣기), 서식 단축키(⌘B 등 Markdown 기호).
- 사용자: 한국 웹소설 연재 작가(1차 = 만든 사람, Ulysses 이주자). 하루 한 회차 5,000자 안팎, 짧은 문단, 대사 많음, 장기 연재(수백 화), 인물 수십 명.

## 1. 특수 시트 — 인물
쓰다 막힐 때 펼쳐 볼 칸 위주.

| 칸 | 형식 |
|---|---|
| 이름 · 별칭 | 한 줄씩 |
| 한 줄 소개 | 한 줄 |
| 성격 | 키워드 3–5 + 설명 |
| 말투 | 1인칭 · 자주 쓰는 어미 · 말버릇 |
| 호칭 | 표: 누구를 → 뭐라고 |
| 반응 | 표: 상황 → 반응 (화날 때, 칭찬받을 때 …) |
| 원하는 것 · 두려운 것 | 한 줄씩 |
| 관계 | 다른 인물 시트 연결 + 한 줄 |
| 비밀 · 복선 | 목록 (회수 예정 회차) |
| 변화 기록 | 회차 → 무엇이 바뀌었나 |
| 메모 | 자유 본문 |

빈 칸 허용, 칸 추가 가능.

## 2. 특수 시트 — 장소
이름 · 별칭 · 종류 · 속한 곳(상위 장소) · 감각(보이는 것 · 소리 · 냄새) · 규칙 · 특징 · 자주 오는 인물 · 있었던 일(회차) · 메모.
(+ 용어/단어장 시트: 이름 · 별칭 · 뜻 — 자동완성 후보)

## 3. 자동완성 — 부를 때만
- `@` 를 치면 인물 · 장소 · 용어 목록. 이어 친 글자 · **초성**으로 좁힘(`@ㅅㅇ` → 서윤). 별칭으로도 찾음. Return 으로 `@` 없이 이름만 들어감.
- ⌃Space: 지금 쓰던 단어를 마무리("벼리" → "벼리섬 등대"). 누르지 않으면 아무것도 안 뜸.
- 한글 조합이 끝난 뒤에만.

## 4. 쓰는 중 도움
- 본문의 이름에 마우스 올림 / ⌥-클릭 → 요약 카드(한 줄 소개 · 말투 · 호칭 · 반응).
- 인스펙터 참조 탭에 "이 회차에 나온 인물 · 장소" 자동.
- 이름 표시는 기본 없음(원하면 옅은 밑줄).

## 5. 저장
- 시트에 종류(일반 · 인물 · 장소 · 용어). 칸 내용은 정해진 제목(`## 말투` …)을 단 Markdown 으로 저장 → 내보내기 · Claude · 다른 앱에서도 읽힘. 앱은 제목 구조를 입력 칸으로 보여줌.
- 형식 변경 → ADR-0010, 기존 시트는 "일반"으로 마이그레이션(변환 전 전체 백업).

## 6. 편의 (같은 묶음)
- 첫 줄 들여쓰기(표시 / 붙여넣기 복사 반영 선택)
- `...` → `…` 자동, 따옴표 · 괄호 짝 닫기
- 특수문자 목록 편집, 줄임말 대치(`;ㄷ` → `―`)
- 맞춤법: 서버 없이 → Mac 안에서 도는 한국어 검사기(Hunspell ko 후보, 라이선스 확인). 한계 크면 외부 검사기 여부 ADR.

## 7. 메인화면
- 통계 없음. 최근 시트 이어 쓰기 + 작품 목록만.

## 순서
① ADR + 화면 spec → ② core(시트 종류, 이름 색인) → ③ 인물 · 장소 입력 화면 → ④ `@` / ⌃Space → ⑤ 요약 카드 · 참조 탭.
