# workbench — 디자인 검수 도구

혼자 쓰는 도구다. 협업 · 승인 흐름은 없다. 피드백은 대화로 agent 에게 바로 준다.

## 이 도구가 하는 일 (목적 → 기능)

| # | 해야 하는 일 | 기능 |
|---|---|---|
| J1 | **전체 파악** — 앱에 어떤 화면 · 상태가 있고 어떻게 이어지는가, 아직 안 만든 화면은 무엇인가 | 홈 두 가지 보기: **흐름**(캔버스, 화면마다 한 줄 + 이동 화살표) · **목록**(화면별 카드 그리드). 계획만 있는 화면은 점선 카드 |
| J2 | **반응형 검수** — 한 화면이 모든 기기 · 창 크기에서 제대로 접히는가 | 상세: 실제 기기 프리셋 프레임(Windows 배율 포함), 끌어서 크기 조절, **폭 스윕**(320→2560 연속 변화 + size class 경계 눈금) |
| J3 | **결함 발견** — 글자 잘림 · 말줄임 · 화면 밖으로 나감 · 낮은 대비 · 영어가 길어서 깨짐 | 프레임마다 **문제 자동 검출**(잘림/말줄임/밖으로 나감 개수 + 표시), 한국어/English 즉시 전환, 토큰 페이지의 **대비표**(WCAG) |
| J4 | **수정 지시** — 무엇을 고쳐 달라는지 agent 에게 정확히 전달 | 프레임마다 **참조 복사**: `화면#상태 · 프리셋 크기 class · platform · 테마 · 언어` 한 줄 |
| J5 | **빠른 이동** — 화면과 상태를 오가며 비교 | 로고 → 홈, 단축키(아래), 화면 전환 메뉴, 이동 경로 패널 |

## 단축키

| 키 | 어디서 | 동작 |
|---|---|---|
| `Esc` | 상세 · 토큰 | 홈으로 |
| `←` `→` | 상세 | 이전 · 다음 상태 |
| `[` `]` | 상세 | 이전 · 다음 화면 |
| `F` | 홈(흐름) · 상세 | 맞춤 |
| `I` | 상세 | 정보 패널 접기/펴기 |
