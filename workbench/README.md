# workbench — 디자인 검수 도구

혼자 쓰는 도구다. 협업 · 승인 흐름은 없다. 피드백은 대화로 agent 에게 바로 준다.

## 이 도구가 하는 일 (목적 → 기능)

| # | 해야 하는 일 | 기능 |
|---|---|---|
| J1 | **전체 파악** — 앱에 어떤 화면 · 상태가 있고 어떻게 이어지는가, 아직 안 만든 화면은 무엇인가 | 홈 두 가지 보기: **흐름**(캔버스, 화면마다 한 줄 + 이동 화살표) · **목록**(화면별 카드 그리드). 계획만 있는 화면은 점선 카드 |
| J2 | **반응형 검수** — 한 화면이 모든 기기 · 창 크기에서 제대로 접히는가 | 상세: **기기 구역**(iPhone · Android · iPad · Mac · Windows) 안에서 그 플랫폼 프리셋만 고르고, 그 플랫폼에 맞는 범위 안에서만 크기 조절 · 추가 · 순서 바꾸기 · 빼기. **폭 스윕**(320→2560 연속 변화 + 레이아웃 경계 눈금) |
| J3 | **결함 발견** — 글자 잘림 · 말줄임 · 화면 밖으로 나감 · 낮은 대비 · 영어가 길어서 깨짐 | 프레임마다 **문제 자동 검출**(잘림/말줄임/밖으로 나감 개수 + 표시), 한국어/English 즉시 전환, 토큰 페이지의 **대비표**(WCAG) |
| J4 | **수정 지시** — 무엇을 고쳐 달라는지 agent 에게 정확히 전달 | 프레임마다 **참조 복사**: `화면#상태 · 프리셋 크기 class · platform · 테마 · 언어` 한 줄 |
| J5 | **빠른 이동** — 화면과 상태를 오가며 비교 | 로고 → 홈, 단축키(아래), 화면 전환 메뉴, 이동 경로 패널 |
| J7 | **써 보기** — 정지 화면이 아니라 실제로 눌러 보며 검수 | 상세의 프로토타입은 **조작 가능**(선택 · 패널 · 토글 · 정리하기). 다른 화면으로 가는 버튼은 그 화면을 연다 → 흐름을 클릭으로 따라간다(← 로 돌아오기). **⤢ 크게 보기**: 한 프레임만 실제 크기까지, 화면을 옮겨 다녀도 유지 |
| J6 | **겁 없이 만지기** — 실험하다 망쳐도 돌아온다 | 모든 편집(프레임 크기 · 프리셋 · 추가/빼기 · 카드 이동 · 자동 정렬)에 **되돌리기/다시 실행**, 드래그 한 번 = 한 단계. **처음 상태로** 한 번에 초기화(이것도 되돌림 가능) |

## 단축키

| 키 | 어디서 | 동작 |
|---|---|---|
| `Esc` | 상세 · 토큰 | 홈으로 |
| `←` `→` | 상세 | 이전 · 다음 상태 |
| `[` `]` | 상세 | 이전 · 다음 화면 |
| `F` | 홈(흐름) · 상세 | 맞춤 |
| `I` | 상세 | 정보 패널 접기/펴기 |
| `Ctrl/⌘+Z` | 어디서나 | 되돌리기 (입력칸 안에서는 그 칸의 글자 되돌리기) |
| `Ctrl/⌘+Shift+Z` · `Ctrl+Y` | 어디서나 | 다시 실행 |

## 조작

- 흐름 · 상세 모두 **움직이는 작업대**: 빈 곳 끌기 · 휠 = 이동, Ctrl/⌘+휠 = 커서 기준 확대. 상세에서 프레임 위를 끌면 프로토타입 조작 — 이동하려면 Space 를 누른 채 끌거나 휠 버튼으로 끈다.
- 화면 밖에 다른 기기 구역이 있으면 위/아래에 칩(↓ iPad · Mac …)이 뜬다. 누르면 그 구역으로.
- 흐름: 줄 제목의 ▸/▾ 로 화면의 상태들을 접고 편다. 앱 뼈대는 기본으로 접혀 있다.
- 되돌리기 기록은 이 탭의 메모리에만 있다 — 새로고침하면 비워진다.
